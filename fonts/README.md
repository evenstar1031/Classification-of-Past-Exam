# fonts

문제지에 쓸 폰트 **두 파일**(보통체 1개 + 굵은체 1개, `.ttf` 또는 `.otf`)을 여기에 올리세요.

지금 쓰는 폰트: **Apple SD 산돌고딕 Neo**
- `AppleSDGothicNeo-Medium.ttf` (본문)
- `AppleSDGothicNeo-SemiBold.ttf` (제목·문제 번호·지문)

규칙
- 굵은체 파일 이름에는 `Bold` 또는 `SemiBold`가 들어가 있어야 합니다. 나머지 하나가 본문용이 됩니다.
- 한 가지 폰트만 두세요. 다른 폰트로 바꿀 때는 기존 두 파일을 지우고 새 두 파일을 올리면 됩니다.
