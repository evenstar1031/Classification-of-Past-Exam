# 전사본 올리는 곳

노트북에서 만든 강의 녹음 전사본(`.srt`)을 넣는 곳입니다. 폴더 하나가 녹음 파일 하나예요.

```
올리기/전사본/
└─ 01.1교시/
   └─ 01.1교시_part00.srt
```

앱의 과목 화면에서 **「내 Claude로 전사본 정리」** 를 누르면, 여기 있는 전사본을 수업별로 분류하고
그 수업 필기본을 근거로 의학 용어를 교정해서 `학습자료/<학기>/<과목>/<번호>_<수업명>/전사본/` 으로 옮깁니다.

음성(mp3)은 여기에 넣지 않습니다. 노트북의 **「GitHub 올리기.bat」** 이 전사에 쓴 MP3를 GitHub 릴리스
[「강의 음성」](https://github.com/seohoe1031/Classification-of-Past-Exam/releases/tag/lecture-audio)에 올리고,
어느 전사본이 어느 MP3인지 `_음성.json` 을 전사본 폴더에 같이 넣습니다. 수업 폴더로 옮길 때
`전사본_<날짜>.음성.json` 이 되어, 앱 전사본 화면에서 문장을 누르면 그 자리부터 녹음이 재생됩니다.
노트북 스크립트는 `_자동관리/노트북/` 에 있습니다.
