# fonts

문제지에 쓸 폰트(보통체 1개 + 굵은체 1개, `.ttf` 또는 `.otf`)를 여기에 둡니다.

지금 쓰는 폰트: **Apple SD 산돌고딕 Neo**
- `AppleSDGothicNeo-Medium.ttf` (본문)
- `AppleSDGothicNeo-SemiBold.ttf` (제목·문제 번호·지문)

규칙
- 굵은체 파일 이름에는 `Bold` 또는 `SemiBold`가 들어가 있어야 합니다(둘 다 있으면 SemiBold). 나머지 하나가 본문용이 됩니다.
- 다른 폰트 파일(KoPub, Pretendard …)이 같이 있어도 됩니다. 그때는 문제지에 Apple SD 산돌고딕 Neo만 씁니다.
- 문제지 폰트를 바꾸려면 이 폴더에 `사용할폰트.txt` 를 만들고 첫 줄에 폰트 파일 이름 일부를 적으세요
  (예: `KoPubWorld Batang`, `Pretendard`). 바꾸면 모든 문제지·해설지가 새 폰트로 다시 만들어집니다.
