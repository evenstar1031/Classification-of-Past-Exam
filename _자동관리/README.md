# _자동관리 — 자동 작업용 폴더

문제지·해설지·학습자료를 만들고 앱을 돌리는 데 쓰는 기록과 프로그램입니다. 평소에는 열어 볼 필요 없어요.
보는 파일은 저장소 맨 위의 `문제지/`·`해설지/`·`학습자료/`·`자료실/` 에 있습니다.

| 폴더 | 내용 |
|---|---|
| `과목정보/` | 과목별 수업 목록 + 연도별 담당 교수 (본1 2학기 3개년 비교 파일에서 만듦) |
| `분류/<과목>/<시험>.json` | 문항마다 어느 수업인지와 그 근거 |
| `해설/<과목>/<시험>.json` | 문항별 정답(원본 표시)·원본 오답노트·해설 — 해설 문장은 여기서 고치면 해설지에 반영 |
| `작업기록/<과목>/<시험>/` | 정답을 지울 때 정한 것들 (문제지를 다시 만들 때 필요) |
| `원본/<과목>/` | 처리가 끝난 원본 기출 PDF (정답 표시 있음) |
| `fonts/` | 문제지 글씨체 (지금 Apple SD 산돌고딕 Neo) — 바꾸는 법은 `fonts/README.md` |
| `app/` | 웹앱 본체(`app.html`), 기출 현황(`gichul_index.json`, 자동 생성), Supabase SQL |
| `tools/` | 위 일을 하는 프로그램 |

## 어떻게 분류하나
1. 문항 위의 `출제자 : ○○○`와 시험 연도로, 그해 그 교수님이 맡은 수업을 찾습니다 (예: 2025년 박지연 → 급성 복통).
2. 한 교수님이 여러 수업을 맡았거나 출제자 표시가 없으면, Claude가 문제 내용과 작년 필기본을 보고 정합니다.
3. 근거는 `분류/<과목>/<시험>.json`에 남습니다. 틀린 게 보이면 Claude에게 `250828 시험 12번은 설사 수업이야` 처럼 말하면 됩니다.
- 새 학년도 기출이면 그해 담당 교수가 `과목정보/`에 있어야 분류가 정확해요. 새 비교 파일을 올리고 `과목정보 업데이트해줘`.

## 자동으로 도는 것 (GitHub Actions)
| 이름 | 언제 | 하는 일 |
|---|---|---|
| 기출 자동 정리 | `올리기/`에 기출이 올라올 때 (+ 한도로 멈췄으면 매시간 재시도) | 정답 지우기 → 분류 → 문제지(Sonnet), 분류 재검토 → 해설(Opus), 결과는 「기출」 이슈 |
| Claude (@claude) | 주인이 제목·댓글에 `@claude` 를 쓴 이슈 | 학습자료 만들기·고치기, 끝나면 결과를 main 에 자동으로 합침 |
| 멈춘 작업 자동 이어 하기 | 매시간 43분 | @claude 작업이 한도 초과·서버 혼잡·준비 실패로 멈추면(시간·턴 초과는 2번까지) 「자동재시도」 라벨이 붙고, 이게 같은 브랜치에서 이어서 돌림(한 번에 5개까지, 이슈당 24번까지). 멈출 때마다 이유를 이슈 댓글로 남김 |
| 문제지·해설지 PDF 만들기 | 분류·해설·원본·폰트·프로그램이 바뀔 때 | 문제지·해설지 PDF를 다시 만들어 저장 |
| 앱 현황 갱신 | 문제지·해설지·학습자료가 바뀔 때 | 앱 「기출·학습자료」 탭 목록(`app/gichul_index.json`) |
| 1학기 자료 정리 | `1학기-` 로 시작하는 Release 를 올릴 때 | 압축을 풀어 `1학기/<과목>/`에 넣고 목록 작성 (Claude 사용량 없음) |

자동 실행은 저장소 주인의 Claude 구독과 Actions 시간을 쓰므로 **주인이 올리거나 연 것에만** 반응합니다.

### Claude 자동 실행 설정 (한 번만)
1. https://github.com/apps/claude 에서 **Install** → 이 저장소 선택
2. 노트북 터미널에서 `claude setup-token` → 나온 `sk-ant-oat01-…` 복사
3. 저장소 `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   이름 `CLAUDE_CODE_OAUTH_TOKEN`, 값은 2에서 복사한 것
4. 아무 이슈에 `@claude 안녕` 이라고 써서 답이 오는지 확인

## 1학기 자료 한꺼번에 올리기
몇 GB짜리 1학기 압축은 저장소가 아니라 **Release** 로 올립니다.
1. 앱 「1학기 자료」 탭 → **GitHub에서 압축 올리기** (또는 Releases → Draft a new release, 태그는 `1학기-` 로 시작)
2. 압축을 끌어다 놓고(파일 하나 2GB까지) **Publish release** → 자동으로 `1학기/<과목>/`에 풀림
3. 똑같은 파일·녹음·영상·100MB 넘는 파일은 빼고, 옛 판은 **지워도 될 것**, 애매한 건 **확인 필요**로 표시
4. 기출은 그대로 넣고 다시 분류하지 않아요. 수업별 문제지로 만들 과목만 탭에서 「수업별 문제지로도 만들기」

## 앱
- 껍데기(로그인 화면·아이콘)는 공개 저장소 `knu1`, 본체는 `app/app.html` — 고치면 다음에 열 때 바로 반영
- 평가·후기·메모는 Supabase (`app/supabase/1_schema.sql`)
- 회원 관리: 앱 오른쪽 위 내 아이디 → 회원 관리. 필기본·기출을 올리려면 이 저장소 Write 초대도 필요

## 직접 돌릴 때 (Claude Code 세션)
`bash _자동관리/tools/setup.sh` 로 준비한 뒤 `올리기 폴더에 있는 기출 정리해줘`, `급성 복통 문제지 다시 만들어줘` 처럼 말하면 됩니다.
저장소를 비공개로 되돌리면 `tools/check_private.py` 의 `ALLOW_PUBLIC` 도 `False` 로.
