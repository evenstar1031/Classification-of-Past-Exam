# 노트북 전사·올리기 스크립트

노트북의 KNUTS 폴더에 있는 파일들의 원본입니다. 여기서 고친 뒤 **노트북의 같은 이름 파일과 바꿔** 쓰면 됩니다
(각 파일을 GitHub에서 열고 「Download raw file」).

| 파일 | 하는 일 |
|---|---|
| `KNUTS 전사.bat` → `knuts-transcribe.ps1` | 녹음을 1시간 단위 MP3로 잘라 Whisper로 전사 → `전사본/<폴더>/…_part00.srt` + 자른 MP3 |
| `GitHub 올리기.bat` → `knuts-upload.ps1` | MP3를 릴리스 「강의 음성」에 올리고 → 전사본과 `_음성.json`(전사본↔MP3 연결)을 저장소 `올리기/전사본/` 에 올리고 → 노트북을 비움 |

## 올리기 후 남는 것 / 지워지는 것 (v2)

| 파일 | 결과 |
|---|---|
| 원본 녹화본 mp4 등 | 노트북에 **그대로** |
| 원본이 mp3 | 그 녹음이 GitHub에 올라간 게 `_음성.json` 으로 확인되면 지움, 아니면 남김 |
| 자른 MP3 | 릴리스에 올라가면 노트북에서 지움 |
| 전사본 .srt, `_원본.txt` | 저장소에 올라가면 노트북에서 지움 |

릴리스 파일 이름 = `녹음날짜_폴더이름(영문·숫자만)_p조각번호.mp3` (예: `20261127_01.1_p00.mp3`). 같은 이름이 이미 있으면 덮어쓰지 않고 `_2` 를 붙입니다.
폴더 이름에 날짜가 없으면 녹음 날짜를 붙여 올립니다(`1127_01.1교시 (인수공통감염병)`).
