# 기출문제 수업별 분류

기출 PDF를 올리면 Claude가 **정답 표시를 지우고, 문항마다 어느 수업에서 나왔는지 분류해서,
수업별 문제지 PDF**로 만들어 줍니다. 해마다 새 기출을 올리면 같은 수업 파일에 이어서 쌓입니다.

> ℹ️ 이 저장소는 동기·후배와 같이 쓰려고 **공개(Public)** 로 둡니다. 올린 파일은 누구나 볼 수 있습니다.
> 다시 비공개로 바꾸려면 저장소 `Settings` → 맨 아래 **Danger Zone** → `Change visibility`,
> 그리고 `tools/check_private.py` 의 `ALLOW_PUBLIC` 을 `False` 로.

## 휴대폰·아티팩트에서 맡기기 (GitHub 이슈 + `@claude`)
`Issues` → `New issue` → **학습자료 만들기** 또는 **기출 정리** 양식을 고르고, 필기본·기출 PDF를 끌어다 놓고 `Submit`.
제목에 `@claude` 가 들어 있어서 GitHub Actions 에서 Claude 가 바로 일을 시작하고, 끝나면 이슈에 PDF 링크를 댓글로 답니다
(보통 20–60분). 고칠 점은 같은 이슈에 `@claude 연습문제 5개 더` 처럼 댓글로.
- 이 방식은 저장소 주인의 Claude 구독과 GitHub Actions 시간을 씁니다. 그래서 **주인이 연 이슈에만** 반응합니다.

## 동기·후배: 내 Claude 로 만들기
아티팩트 「기출·학습자료」 탭의 **내 Claude로 만들기** 를 누르면 Claude Code 가 이 저장소와 요청 문장이 채워진 채 열립니다.
필기본(또는 기출 PDF)을 첨부하고 보내면, 자기 Claude 구독으로 만들어져 이 저장소에 올라갑니다.
처음 한 번: ① 저장소 주인에게 GitHub 아이디를 알려 초대(Write) 받고 메일에서 수락 ② claude.ai 의 Claude Code 에서 GitHub 연결.
- 첨부는 파일당 25MB 까지. 더 크면 `학습자료/<과목>/<번호>_<수업명>/필기본/` 에 직접 올리고 이슈에는 수업만 적으세요.
- 처음 한 번 설정이 필요합니다 → 아래 "Claude 자동 실행 설정".

### Claude 자동 실행 설정 (한 번만)
1. https://github.com/apps/claude 에서 **Install** → 이 저장소 선택
2. 노트북에 Claude Code 를 설치하고(설치 안내: https://code.claude.com/docs) 터미널에서 `claude setup-token` → 나온 `sk-ant-oat01-…` 복사
3. 저장소 `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   이름 `CLAUDE_CODE_OAUTH_TOKEN`, 값은 2에서 복사한 것 → `Add secret`
4. `Issues` 탭에서 아무 이슈에 `@claude 안녕` 이라고 써서 답이 오는지 확인

## 매번 할 일
1. **기출 올리기** — `올리기` 폴더 → 과목 폴더(예: `진단의기본`) → `Add file → Upload files`
   - 파일 이름에 시험 날짜를 넣어 주세요. 예: `250828_진단의기본.pdf` (연도 판단에 씁니다)
2. **Claude Code 클라우드 세션**에서 이 저장소를 고르고:
   > 올리기 폴더에 있는 기출 정리해줘
3. **결과 보기** — `문제지/<과목>/` 폴더
   - `README.md`: 수업 × 연도별 문항 수 표 (폴더를 열면 바로 보입니다)
   - `09_급성 복통.pdf` 처럼 수업마다 한 파일, 최신 연도부터
   - `00_전체_수업순.pdf`: 전 수업을 한 권으로
   - `시험별/`: 시험 통째로 정답만 지운 버전
   - 파일을 누르고 오른쪽 위 다운로드 버튼(↓)
   - Claude가 "Pull Request를 만들었다"고 하면: `Pull requests` 탭 → 초록색 `Merge` 버튼

## 필기본으로 학습자료 만들기
수업 하나의 **설명 + 기출 + 연습문제** PDF를 만듭니다. 글씨체는 저장소에 들어 있어서 첨부하지 않아도 됩니다.

1. Claude Code 클라우드 세션에서 이 저장소를 고르고, 필기본 파일을 첨부해서:
   > 치료의 기본 응급기도관리 필기본이야. 학습자료 만들어줘
   - 작년 필기본도 있으면 같이 첨부하고 "작년 것도 있어"라고 말하면 됩니다.
   - 첨부 대신 `학습자료/<과목>/<번호>_<수업명>/필기본/` 에 올려도 됩니다.
2. 결과: `학습자료/<과목>/<번호>_<수업명>_학습자료.pdf` (대화창으로도 보내 줍니다)
   - **1부 개념 설명** — 필기본 전체 내용 설명 (작년과 다른 점, 기출 포인트 표시)
   - **2부 기출문제** — 그 수업으로 분류된 기출 전부 (문제지와 같은 모양), 끝에 정답·해설 모음
   - **3부 연습문제** — 새로 만든 문제, 끝에 해설 모음
3. 고치고 싶으면: `연습문제 5개 더`, `1부에서 ○○ 부분 더 자세히`, `기출 3번 해설 틀렸어` 처럼 말하면 됩니다.

기출은 `분류/` 에 정리된 것만 들어갑니다. 아직 분류 안 된 과목은 먼저 기출을 `올리기/` 에 올려 정리하세요.

## 앱 (브라우저에서 바로, 홈 화면에 추가)
시간표 · 강의계획서 · 교수 평가 · 기출·학습자료 · 1학기 후기를 Claude 밖에서 쓰는 웹앱입니다.
- **껍데기**(로그인 화면·아이콘)는 공개 저장소 `knu1` 에 있고 내 도메인으로 서비스됩니다. 기출·후기 내용은 들어 있지 않습니다.
- **본체**는 이 저장소의 `app/app.html`, 기출 현황은 `app/gichul_index.json`(main 에 올라올 때마다 `app-index.yml` 이 자동 갱신).
  초대받은 사람이 GitHub 로 로그인했을 때만 앱이 GitHub API 로 읽어 옵니다.
- **평가·후기·메모**는 Supabase 에 저장됩니다. 표와 보안 규칙은 `app/supabase/1_schema.sql`, 아티팩트에서 옮긴 데이터는 `2_seed.sql`.
- 회원 관리: 앱 오른쪽 위 내 아이디 → 회원 관리 (보기 / 후기 작성). 기출 PDF를 열려면 이 저장소 초대(Read 이상)도 따로 필요하고,
  필기본·기출을 올리려면 Write 가 필요합니다.
- 앱을 고칠 때는 `app/app.html` 을 고치면 됩니다(다음에 열 때 바로 반영).

## 어떻게 분류하나
`과목정보/`에 과목별 수업 목록과 **연도별 담당 교수님**이 들어 있습니다
(본1 2학기 3개년 비교 파일에서 만들었습니다: 진단의 기본, 치료의 기본, 인체감염학,
정신건강의학, 신경학, 호흡기·알레르기병학, 사례바탕의료인문1).

1. 문항 위의 `출제자 : ○○○`와 시험 연도로, 그해 그 교수님이 맡은 수업을 찾습니다.
   (예: 2023년 송승호 → 급성 복통, 2025년 박지연 → 급성 복통)
2. 한 교수님이 여러 수업을 맡았거나 출제자 표시가 없으면, Claude가 문제 내용을 보고 정합니다.
3. 근거는 `분류/<과목>/<시험>.json`에 남습니다. 틀린 게 보이면 이렇게 말하면 됩니다:
   > 250828 시험 12번은 설사 수업이야
