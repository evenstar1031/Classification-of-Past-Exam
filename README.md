# 본과 1학년 기출 · 학습자료

경북대 의대 본과 1학년 기출을 **정답 없이 수업별로** 나눈 문제지, 따로 모은 정답·해설, 필기본으로 만든 학습자료를 모아 둔 곳입니다.
앱(**본과 1학년** 웹앱)의 「기출·학습자료」 탭에서도 같은 파일을 바로 열 수 있어요.

> ℹ️ 동기·후배와 같이 쓰려고 **공개**로 둔 저장소입니다. 올린 파일은 누구나 볼 수 있어요.

## 어디를 보면 되나

| 폴더 | 들어 있는 것 |
|---|---|
| 📘 [`문제지/`](문제지) | 수업별 기출 문제지 — **정답 표시 없음**. 과목 폴더를 열면 수업 × 연도 문항 수 표가 바로 보여요 |
| ✅ [`해설지/`](해설지) | 같은 문제지에 정답·해설을 붙인 판 (`…_정답해설.pdf`) |
| 📗 [`학습자료/`](학습자료) | 필기본으로 만든 수업별 학습자료 — 1부 설명 · 2부 기출 · 3부 연습문제 |
| 📁 [`자료실/`](자료실) | 직접 만든 정리본 — `01. 진단의 기본` … `07. 사례바탕의료인문1` 과목 폴더에 올리기 (파일 이름 앞 번호 = 수업 번호) |
| 📤 [`올리기/`](올리기) | 새 기출 PDF를 넣는 곳 — 넣으면 자동으로 정리돼요 |
| ⚙️ [`_자동관리/`](_자동관리) | 분류 기록·원본·프로그램·앱 등 자동 작업용. **열어 볼 필요 없어요** |

과목 폴더 안의 파일 이름 규칙
- `09_급성 복통.pdf` — 수업 번호_수업 이름, 최신 연도 문제부터
- `00_전체_수업순.pdf` — 모든 수업을 한 권으로
- `시험별/` — 시험지 통째로 (원래 문항 번호 그대로)
- 이름 끝 `(수정)` — 수업을 다시 나누거나 고친 파일

## 새 기출·필기본 맡기기

- **앱에서** — 「기출·학습자료」 탭이나 시간표의 수업 칸에서 **필기 올리기 / 바로 만들기 / 내 Claude로 만들기**
- **기출 PDF** — `올리기/<과목>/` 에 올리면 정답 지우기 → 수업 분류 → 문제지·해설지까지 자동(보통 30–90분).
  파일 이름에 시험 날짜를 넣어 주세요 (예: `250828_진단의기본.pdf`)
- **휴대폰 GitHub** — `Issues` → `New issue` → **학습자료 만들기** / **기출 정리** 양식에 파일을 끌어다 놓고 `Submit`.
  끝나면 이슈 댓글로 링크가 와요. 고칠 점은 같은 이슈에 `@claude 연습문제 5개 더` 처럼
- 분류가 틀렸으면 Claude에게 `250828 시험 12번은 설사 수업이야` 처럼 말하면 돼요

동기·후배는 앱의 **내 Claude로 만들기**로 각자 Claude 구독을 써서 만들 수 있어요(처음 한 번: 저장소 주인에게 GitHub 아이디를 알려 초대 받기).
자동 실행 설정, 분류 방법, 1학기 자료 올리기 같은 자세한 안내는 [`_자동관리/README.md`](_자동관리/README.md)에 있어요.
