# 기출문제 수업별 분류

기출 PDF를 올리면 Claude가 **정답 표시를 지우고, 문항마다 어느 수업에서 나왔는지 분류해서,
수업별 문제지 PDF**로 만들어 줍니다. 해마다 새 기출을 올리면 같은 수업 파일에 이어서 쌓입니다.

> ⚠️ **먼저 저장소를 비공개로 바꿔 주세요.** 지금 공개(Public) 상태라면 기출이 누구에게나 보입니다.
> 저장소 위쪽 `Settings` → 맨 아래 **Danger Zone** → `Change visibility` → `Make private`.
> 비공개가 아니면 Claude가 기출 파일을 저장(커밋)하지 않도록 막혀 있습니다.

## 처음 한 번만
1. 위 안내대로 저장소를 **Private**로 바꾸기
2. `fonts` 폴더에 KoPubWorld 바탕체 Pro **Medium**, **Bold** 두 파일(.otf) 올리기

## 매번 할 일
1. **기출 올리기** — `올리기` 폴더 → 과목 폴더(예: `진단의기본`) → `Add file → Upload files`
   - 파일 이름에 시험 날짜를 넣어 주세요. 예: `250828_진단의기본.pdf` (연도 판단에 씁니다)
2. **Claude Code 클라우드 세션**에서 이 저장소를 고르고:
   > 올리기 폴더에 있는 기출 정리해줘
3. **결과 보기** — `문제지/<과목>/` 폴더
   - `README.md`: 수업 × 연도별 문항 수 표 (폴더를 열면 바로 보입니다)
   - `09_급성 복통.pdf` 처럼 수업마다 한 파일, 최신 연도부터
   - `00_전체_수업순.pdf`: 전 수업을 한 권으로
   - `시험별/`: 시험 통째로 정답만 지운 버전
   - 파일을 누르고 오른쪽 위 다운로드 버튼(↓)
   - Claude가 "Pull Request를 만들었다"고 하면: `Pull requests` 탭 → 초록색 `Merge` 버튼

## 어떻게 분류하나
`과목정보/`에 과목별 수업 목록과 **연도별 담당 교수님**이 들어 있습니다
(본1 2학기 3개년 비교 파일에서 만들었습니다: 진단의 기본, 치료의 기본, 인체감염학,
정신건강의학, 신경학, 호흡기·알레르기병학, 사례바탕의료인문1).

1. 문항 위의 `출제자 : ○○○`와 시험 연도로, 그해 그 교수님이 맡은 수업을 찾습니다.
   (예: 2023년 송승호 → 급성 복통, 2025년 박지연 → 급성 복통)
2. 한 교수님이 여러 수업을 맡았거나 출제자 표시가 없으면, Claude가 문제 내용을 보고 정합니다.
3. 근거는 `분류/<과목>/<시험>.json`에 남습니다. 틀린 게 보이면 이렇게 말하면 됩니다:
   > 250828 시험 12번은 설사 수업이야
