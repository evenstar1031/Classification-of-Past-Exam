## 1. 정의와 역학 (04:10–09:05)

- 장소로 세 가지: **CAP / HAP / VAP**, 시간으로 구분(★11). 48시간 이전은 잠복기 상태에서 들어온 것 → CAP. "의료 관련 감염 정의에도 나옵니다."
- **CAP 사망률 5–15%** — 고령자가 늘어 잘 안 줄어든다.
- 감염 진료 순서: 열 → **위치(폐렴? 요로? 장염? 연조직? 수막염?)** → 그 부위의 **가장 흔한 원인균** → 항생제.
- 중증도(치료 장소)별 원인균: 외래 = 폐렴알균, 마이코플라스마, 호흡기 바이러스 / 입원 = + 레지오넬라, S. aureus / 중환자실 = + *E. coli*·*Klebsiella* 같은 그람음성, 레지오넬라(중증 폐렴 원인). 이 구분은 "**나중에 치료에도 딱 그대로 적용**".

## 2. 정형 vs 비정형과 항생제 정리 (09:05–14:57)

- 정형균(*S. pneumoniae*, *K. pneumoniae*, *H. influenzae*): 기침·가래·호흡곤란·열, X선 **경화(consolidation), 대엽성 폐렴**.
- 비정형균: **호흡기보다 전신 증상**(근육통, 열, 관절통, 발진), X선 **간질성** — "대체로 그렇다는 거지 100% 구분 X".
- 페니실린 계열: 페니실린 → *S. aureus*는 페니실리네이스로 안 들음 → **암피실린/설박탐, 아목시실린/클라불라네이트** — CAP에서 억제제 조합을 쓰는 이유는 **H. influenzae(β-lactamase 생성, 외래 2위)**.
- 세파: 2세대는 "본과 1학년은 그냥 잊어버리고". **1세대 = MSSA·연조직염·화농연쇄구균** / **3세대(세프트리악손·세포탁심) = 폐렴알균·H. influenzae·K. pneumoniae** — 얼마 전까지 전 세계 1등 항생제, 지금은 녹농균 커버가 필요해져 **피페라실린/타조박탐이 1등**(고령·면역저하·입원·다제내성 증가).
- 비정형균엔 위 약이 하나도 안 듣고 → **마크롤라이드(에리스로·아지스로·클래리스로)**, 아지스로마이신을 제일 많이 씀(약물상호작용·부작용 적음). **FQ는 폐렴알균과 비정형 둘 다** → 단독이면 FQ, 둘이면 β-lactam + 마크롤라이드, 중증이면 β-lactam + FQ.
- 폐렴알균 페니실린 내성: "본과생한테는 좀 어려운 수준" — **학생 수준에서는 폐렴알균에 페니실린이 효과적**이라고 알면 된다(80년 된 약인데 여전히 유효).
- 내성 정리(★5·6).

## 3. 병리기전·임상·진단 (14:57–21:16)

- 숙주·병원체·균량. **비인두에 집락 → 방어 기전(면역, 섬모 운동)이 약해져 폐로 흡인** — 주요인.
- 증상: 호흡기(기침, 가래, 호흡곤란, **흉막 침범 시 흉통**) + 전신(열·오한). 상기도 증상(인후통, 콧물)은 대부분 바이러스.
- **노인은 20–30%가 의식 혼탁으로 온다** → 신경과로 먼저 가서 뇌 MRI 정상 → 감염 → 치료 지연 가능(국내 응급실은 한꺼번에 검사해서 실제론 드묾).
- X선: 우중엽 대엽성 폐렴, 간질성(뉴모시스티스·마이코플라스마·클라미디아·레지오넬라). **영상만으로 원인균 예측 X**. 탈수·면역저하·뉴모시스티스는 초기에 안 보일 수 있음. 초음파는 잘 안 함.
- **폐렴처럼 보이는 병이 너무 많다** → 치료가 안 되면 "**이거 딴 거 아니야?**".
- 혈액배양: 입원하면 함. 양성일 정도면 상태가 아주 나쁨(*K. pneumoniae* 균혈증 폐렴 50%가 5일 만에 사망) — 대신 원인균은 확실.
- **객담**: 입안 균 때문에 **오염균 80–90%, 진짜 10–20%**. **WBC 많으면 진짜 객담, 상피세포 많으면 침**.
- 염증표지: CRP, **프로칼시토닌 — 주로 "언제 끊을래"에 활용**.
- **소변 항원검사: 폐렴알균·레지오넬라**. **분자진단(20여 가지 동시 PCR)** — 약 20만 원, 국내는 중환자실만 보험, 교수님 RCT 진행 중. 인플루엔자·코로나 항원검사.

## 4. 중증도 평가 (21:22–24:31)

- **CURB-65**(★1): **0–1점 외래**(먹는 약, 3일 뒤 다시) / **2–3점 일반 병실** / **4–5점 중환자실** — 4–5점이면 "안 해 봐도 압니다". **나이가 모든 리스크를 뛰어넘는다**.
- 패혈성 쇼크로 **승압제(노르에피네프린, 에피네프린, 바소프레신)** 를 분당 용량으로 인퓨전 펌프로 줘야 하면 중환자실.
- 외래에서 피검사가 안 되면 **BUN 빼고(CRB-65)** 판단.
- **PSI**: 복잡해서 "AI가 계산해 주지 않을까". **나이는 점수 그대로(70세 = 70점)** → 90세면 다른 것 없어도 입원.

## 5. 경험적 항생제 (24:34–32:49)

- 표: β-lactam / 마크롤라이드 / FQ. 정형 = β-lactam 또는 FQ, 비정형 = 마크롤라이드 또는 FQ.
- **FQ 두 종류**: 시프로 = 그람음성(복강내·요로감염), **폐렴 X** / **제미·레보·목시 = 호흡기 FQ(항폐렴알균 FQ)**, 비정형에도 잘 들음(★7).
- **β-lactam도 녹농균 위험 여부로 두 종류**: 항폐렴알균 + 항녹농균 = **4세대 세파, 피페라실린/타조박탐, 이미페넴·메로페넴**. "학생 수준에서는 그렇게만 정리하면 더 이상 할 필요 없지 않을까."
- 장소별 약(★8). "외래는 비정형 감염이 별로 없다." 입원 주사 약과 외래 경구 약은 **계열이 같다**.
- 원인균이 나오면 맞춤 치료 — 그런데 CAP는 **원인균을 잘 못 밝히고 나와도 원인균이 아닌 경우가 많아 경험적 치료가 훨씬 중요**. 단 **혈액·흉수·CSF(무균 검체)** 에서 자라면 원인균. "이거(원인균별 표)는 몰라도 됩니다."

## 6. 치료 기간·반응·예방 (32:53–36:13)

- 좋아지면 경구 전환. 가장 짧은 연구는 3일이지만 "앵간히 용감하지 않고는" — 보통 **5일, 7일**, 아주 심하면 10일. 안정되면 퇴원.
- **치료 실패는 약제 내성보다 진단이 틀린 경우가 훨씬 많다**. **X선은 금방 안 좋아짐**(한 달 지나도 남음, 치료 기간과 무관) — 고령·암 의심·비전형 병변이면 **한 달 뒤 추적 X선**.
- "감염내과 외래에서 제일 많이 하는 말 = **이제 안 오셔도 됩니다**."
- 예방: **폐렴사슬알균 단백결합 백신(PCV, 프리베나)** — 소아 2·4·6·12–15개월 4회, 효과가 좋아 성인으로 확대(다음 주 성인 예방접종 시간에). 인플루엔자, COVID-19 백신. 기저질환이 제일 중요.

## 7. HAP (36:13–41:16)

- 원인균·정의(★11). **전체 입원의 일부, 중환자실 인공호흡기면 25%까지**, 사망률이 CAP보다 월등히 높음(다제내성 + 나쁜 환자 상태). 위험인자(★12).
- 진단: 하기도 검체. **CPIS**(기도 분비물, X선, 체온, 백혈구, PaO₂/FiO₂, 미생물) — "**이런 게 있다는 정도 알면 되고**", 구체적으로 알아야 할 건 CAP.
- **조기(5일 이내) 발생은 CAP와 균주가 비슷**, 늦은 발생은 다제내성.
- 치료: **4세대 세파·피페라실린/타조박탐·카바페넴(항녹농균) + 아미노글리코사이드 또는 시프로·레보** = **CAP 중환자실 녹농균 위험 환자 치료와 같다**. 기간 **7–8일**(실제론 2–3일 더 씀 — 연구 환자만큼 깔끔하지 않아서).
- 정리: CAP 원인 폐렴알균, 국내 폐렴알균 마크롤라이드 내성 높음, 진단 = 호흡기 증상 + 전신 증상 + X선, CURB-65로 장소 결정 → 약 결정, HAP = 48시간 이후·그람음성 다제내성균.

## 학습자료(필기본)와 다른 점·확인할 점

1. **CURB-65 장소 기준**: 수업 "**2–3점 일반 병실, 4–5점 중환자실**". 학습자료 슬라이드 "0–1 외래 / **2 입원** / 3–5 입원, 4–5점이면 중환자실 고려", 핵심정리 "**3점 이상은 중환자실 고려**". 시험에 "3점"이 나오면 학습자료 정리대로 **입원(중증), 중환자실 고려**가 안전하다.
2. **CAP 치료 기간**: 수업 앞부분 "일반적으로 **5일, 7일**", 끝부분 "지역사회 폐렴은 **3에서 5일** 했죠, 짧게 보면". 학습자료 핵심정리 5번 **3–5일(최소 5일)**.
3. 페니실린 발견 이야기에서 "1940년대 벤자민…"이라고 했는데, 페니실린은 **1928년 알렉산더 플레밍** 발견(1940년대 실용화). 시험과는 관계없음.
4. 수업 중 "어제 **배소현** 교수님한테 배웠나요"(전사 "배수연") — 01강 세균감염의 치료와 예방의 항생제 정리를 말한다.
5. 교수님이 말한 **"항생제 표(β-lactam 세대 줄 긋기)"** 는 **의료관련감염 강의록에 올려 두었고 목요일에 다시 정리**한다고 했다 → 13강 의료관련감염 및 감염관리 자료와 같이 볼 것.
6. **MRSA**: 수업 "미국에서 문제였다가 줄고 있다, 국내 경험적 치료 거의 불필요". 학습자료에는 인플루엔자 후 S. aureus 합병, MRSA → 괴사성 폐렴이 있다(원인균 문제로 나올 수 있음).
