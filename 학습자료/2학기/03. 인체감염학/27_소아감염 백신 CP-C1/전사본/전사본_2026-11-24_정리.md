## 수업 흐름

1. **총론**(00:35–20:21): 좋은 백신의 조건 → 수동·능동 면역 → 백신 종류(생·사·단백결합·핵산) → 접종 일정과 나이 계산 → 동시 접종·간격 → 면역글로불린과의 간격 → 접종 방법·부위 → 금기·연기 → 과민반응(계란) → 이상반응과 인과성 평가.
2. **각론**(20:28–41:24): BCG → B형간염 → DTaP/Tdap → 폴리오 → Hib → 폐렴구균 → MMR → 수두 → 일본뇌염 → 인플루엔자 → A형간염 → HPV → 로타 → 수막알균 → 공수병 → RSV 단클론항체.
3. **마무리**(41:34–42:53): "**맞는 시기, 대상, 예방하는 질병** 위주로 보고, **각 접종 나이는 외워야** 한다. 1세 때 병원 가면 맞는 접종 같은 것." 실습 때·본4 때 다시 수업한다 — "너무 상심하지 마십시오, 다 할 수 있습니다."
