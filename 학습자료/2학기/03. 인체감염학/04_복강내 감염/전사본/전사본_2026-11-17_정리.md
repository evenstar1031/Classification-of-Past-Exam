## 1. 복강의 구조와 감염의 발생 (03:00–10:35)

- 벽측·장측 복막, **복막내 장기 vs 후복막 장기**(췌장, 십이지장, 상행·하행결장 / 신장, 요관, 부신). 가로결장간막으로 위·아래 구분, lesser sac 등 빈 공간.
- **정상 복수**: 장액, 단백(주로 알부민) **<30**, 백혈구 **<300**(주로 단핵구). 세균이 들어오면 초기 **다형핵구(PMN)** → 이후 단핵구 → 케모카인·사이토카인 → 염증.
- 간경화·심부전·만성 콩팥병 → 복수 → 세균 침입 → 복막염.
- **농양 호발 = 기대는 자리(dependent)**: **골반, 좌·우 횡격막하, 모리슨 파우치**(간·신장 사이). 겸상인대가 좌우 이동을 어느 정도 막음.
- 원인: 해부학적 장벽 파괴 — 충수·게실·궤양 파열, **장벽 약화**(허혈, 암, 크론병 같은 IBD), 췌장염, 골반염.
- **두 단계**: ① **복막염** — 주로 *E. coli*, **패혈증·내독소로 초기 사망** ② 국소적·완만하게 남으면 **농양** — **혐기균(*B. fragilis*) 우세**.
- 복막염 CT: 복막 비후·조영 증강, 주변 지방 침윤(지저분한 양상).

## 2. 복막염 분류와 SBP (10:35–22:56)

- 국소/전반, 급성/만성, 감염성/화학성. **1차(저절로) / 2차(천공 등 구조적 문제) / CAPD 관련 / 결핵성** (★1).
- **SBP 기저질환**: **간경화(특히 알코올성)**, 전이성 암, 간염, 심부전, 루푸스 등 자가면역질환, 림프부종. 드물게 없이도. **간경화 환자의 10% 이하**.
- 복수가 차는 이유: 문맥압 ↑, 알부민 ↓(삼투압).
- **기전**: 간 기능 ↓ → **보체 ↓**, 문맥 우회(간의 거름 역할 소실), **옵소닌화·포식 능력 ↓**, **복수 = 좋은 배지**, 장내 세균 불균형(dysbiosis), **세균 전위(translocation)**.
- **임상**: 대부분 열. 복수가 원래 있었으니 복수만으로 판단 X. 복통·복막 자극 징후는 없는 경우도 많고 **비특이적**(근육통, 피로, **간성뇌증**, 황달·빌리루빈↑, 크레아티닌↑) → **"복수 있는 간경화 환자가 열이 나면 SBP를 의심하고 복수천자"**.
- **복수천자**: **LLQ, ASIS와 배꼽 사이 2–3 cm 안쪽**, 천천히 찔러 장이 밀리게 — "인턴 가서 충분히 할 것들".
- 진단(★2), 배양(★4), 원인균(★3), 천공 배제(★5).
- 치료 시점: 열, 복통·압통, 설명 안 되는 의식 변화, AKI·산증·백혈구 증가, **복수 PMN ≥250**. **항생제가 늦으면 사망률 ↑** → 검체 채취 후 바로 경험적 항생제. 균 확인 후 감수성에 맞게 변경. **치료 후에도 복수 호중구가 많으면 다른 진단을 찾는다**.

## 3. 2차 복막염 (22:59–28:39)

- 속빈 장기 천공·파열 → 내용물 → 복합균(★6). 숙주가 피브린·호중구 삼출물로 막으려 함. 혈액에선 *E. coli* 흔하지만 ***Bacteroides* 균혈증**도.
- **천공 부위별**: 위·십이지장 궤양 천공은 **위액 pH가 낮아** 균이 덜 삼 / **대장 천공은 pH가 높고 균이 많고 섞여 있어 문제**. 국소 통증 먼저(위 → 명치, 충수 → 배꼽 주위·RLQ, 하행결장 → LLQ).
- 벽측 복막 침범 → 통증 급증: **무릎 굽히고 웅크림**, 기침·재채기에 아픔, **근성방어(guarding)·반발통**. 열, 백혈구 증가, **좌방이동(left shift)**, 선 자세 X-ray **횡격막 아래 free air**.
- 진단: **복수천자는 1차 검사 아님**. 오래 꽂아 둔 **배액관에서 나온 배양은 신뢰도 낮음**.
- 치료(★6·7). 모노박탐도 가능.

## 4. CAPD 복막염과 결핵성 복막염 (28:44–32:20)

- **CAPD**(★8): 카테터가 피부를 뚫고 있어 **피부균**. 투석액은 원래 WBC가 더 적어야 함. 치료 = 그람양성 → **세파졸린**, 그람음성 → **세프타지딤 또는 아미노글리코사이드** 병용. 중증이면 정맥으로도 추가.
- **결핵성**: "이건 그냥 듣고 넘어가면 됩니다". CT에서 엉기고 경계 불분명, 결절. 림프절·장기 결핵의 **직접 전파** 또는 **속립결핵(혈행성)**. **만성·완만**("몇 개월 동안 배가 불렀는데요"), 비특이적 복통·열·이유 없는 복수. 복수 **림프구 우세**, 배양률 낮음 → PCR → 안 되면 **복막 생검**. 치료 **결핵약 9개월**.

## 5. 복강내 농양 (32:20–38:02)

- 복막에서 시작한 농양 vs 간·비장 같은 **장기 농양**. 농양 = 균 + 호중구 + 섬유성 피막 — 질병이면서 **균이 퍼지는 걸 막는 숙주 방어 반응**.
- 원인균(★10). 복강내 감염의 **74%가 복막(내·후) 농양**. 부위: 그물막, 장간막, 골반, 요근, 횡격막하, 장기 표면.
- 원인: 대장 파열·염증, 여성 **난관난소 농양**, **췌장염**.
- 진단(★12): CT가 가장 중요. 초음파, 갈륨 스캔·PET-CT는 거의 안 씀. 예전엔 탐색적 복강경.
- 치료(★9).

## 6. 장기 농양 (38:02–45:56)

- **간농양**(★11): 담도 → **장내 그람음성균·장알균**(혐기균은 일반적으로 고려 X) / 문맥 → **호기·혐기 둘 다** / 혈행성(균혈증 선행) → **S. aureus, 연쇄구균** / ***K. pneumoniae*** — 끈적해서 잘 들러붙어 **전이성 감염** / **칸디다 → 면역 상태 확인**(항암, 면역억제제).
  - 증상: 열, 복통, **RUQ 압통**, 백혈구 증가, **ALP ↑**. RUQ 증상이 뚜렷하지 않으면 의심하기 어려움 → CT.
  - CT 모양: *Klebsiella* 간농양, **아메바 = 크고 하나**, **칸디다 = 점점이 여러 군데**.
- **비장 농양**: 굉장히 드물지만 놔두면 치명적. 주로 **균혈증의 혈행성 전파 — 감염성 심내막염의 합병증**, 면역저하자. LUQ 통증, **비장비대 약 절반**, **진단 전 평균 20일 발열**(놓치기 쉬움), 대개 우연히 발견. 배액 노력, **개수가 많으면 비장절제**. 비장절제 후 **협막균 백신 3가지: 폐렴알균, *H. influenzae*, 수막알균**.
- **신주위·신장 농양**: 드묾, **75%가 요로감염 기원**. **결석 같은 요로 폐쇄** → APN → 농양. 원인균 *E. coli*, *Proteus*, *Klebsiella*. 소변 칸디다는 보통 정상균이지만 면역저하·요관 폐쇄 땐 드물게 원인.
- **요근 농양**: "생각보다 꽤 많다". 경로: 혈행성 / 복강·골반에서 직접 / **척추염·골수염**에서 인접 전파. 원인균: 혈행성 골수염 → **S. aureus**, 복강·골반 기원 → **장내 혼합균**. **Pott병(결핵)** 도 있음. 열 + 허리 통증 + **엉덩이·무릎으로 방사통**. 진단 CT, 치료 **배액 + 원인균 항생제**.
- 복강내 감염 경험적 항생제 다시: **3세대 세파 + 메트로니다졸**, 또는 **피페라실린/타조박탐, 카바페넴, 티게사이클린 단독**.

## 학습자료(필기본)와 다른 점·확인할 점

1. **결핵성 복막염 치료 기간**: 수업 "**9개월** 정도", 학습자료 "**9–12개월**". 같은 범위의 시작으로 보면 된다.
2. **요근**: 수업에서 "소아스 머슬, **허리 기립근**"이라고 했는데, 요근(psoas, 큰허리근)은 척추기립근이 아니라 **허리뼈 앞옆에서 넙다리뼈로 가는 근육**(후복막). 해부 문제가 나오면 주의.
3. **CAPD 치료**: 수업 "세파졸린, 세프타지딤, 혹은 아미노글리코사이드" — 학습자료 정리는 **세파졸린(또는 반코마이신) + 세프타지딤 또는 아미노글리코사이드, 복강내(IP) 투여**. 반코마이신은 수업에서 말하지 않았다.
4. **SBP 원인균**: 수업 "E. coli 단연 으뜸, 단일균". 작년 교수님은 "요즘은 Klebsiella가 더 우세"라고 했지만 올해 슬라이드·수업 모두 **E. coli** — 시험은 E. coli.
5. **숫자 함정**: SBP **PMN ≥250** vs CAPD **WBC ≥100 + PMN ≥50%** vs 정상 **WBC <300(단핵구)**. 수업에서 셋 다 말했다.
6. 비장 농양 CT를 "하이퍼덴스한 병변"이라고 했지만 농양은 보통 **저음영(hypodense)** 으로 보인다 — 말실수로 보인다(srt는 말한 대로 둠).
