## 1. 급성 설사 질환의 분류 (17:48–25:48)

- AGE = 장에 염증. 원인: 감염성 / 비감염성(알레르기, 크론병 같은 만성 질환, 약물(항생제), IBS(찬물·마라탕), 흡수장애, 전신감염(패혈증), **비경구성(parenteral) 설사** — 중이염·폐렴 때 설사, 심리적).
- 부위별 이름: 위장염, 장염, 장결장염, 회결장염, 말단 회장염.
- **하루 장액 흐름**: 마시는 물 2000 + 침 1500 + 위액 2000 + 담즙 500 + 췌액 1500 + 장액 1500 ≈ **9000 cc** → **소장에서 8500 cc 흡수**, 대장에서 약 400 cc, 나머지 배설. "나중에 여러 장기 공부할 때 도움이 된다."
- 식품매개 질환 안에 식중독과 감염성 AGE(세균·바이러스)가 있다. 영어로 "stomach flu냐 food poisoning이냐".
- 균별: ETEC·비브리오(콜레라)는 물설사만, **아메바는 혈성 점액변이지만 WBC가 잘 안 나옴**, 지아르디아는 물설사. 바이러스는 로타·노로(옛 노워크, 칼리시바이러스) 대표, 아데노·아스트로는 잘 안 찾음. 면역저하자 **CMV 대장염**. 세균성 장결장염: 살모넬라, 시겔라, *E. coli*, 캄필로박터, 여시니아, 비브리오, *V. parahaemolyticus*, 항생제 후 ***C. difficile***.
- 정리: **장염 = 비염증성**(바이러스, ETEC·콜레라 등) / **장결장염 = 염증성**(세균성, 아메바) / 만성은 UC·크론(IBD), IBS.

## 2. 캄필로박터와 여시니아 (25:51–38:10)

- 계란·닭(★5), 냉장고(★3): 캄필로박터는 **4℃에서 생존, 산소가 적은(미호기성) 조건**에서 자람. 여시니아도 상온보다 낮은 온도에서 자람. 둘 다 **특수 배지·특수 인큐베이터** 필요.
- 캄필로박터: 균혈증·관절염까지. 감염 경로 — **덜 익힌 닭 등 가금류**, 교차오염, **살균 안 된 지하수·계곡물·약수**, 가축 접촉. 일본 **나가시 소멘** 집단 감염(새가 물을 오염).
- **GI 패널 PCR**로 한꺼번에 검사. 예전엔 대변 현미경 WBC로 세균성을 알았고, **아메바는 신선한 대변을 30분 안에** 들고 가서 움직이는 영양형(trophozoite)을 봐야 함 → 놓치면 **크론병·UC로 오인**. 캄필로박터·여시니아도 배양이 안 돼 IBD로 오인되어 엉뚱한 치료를 받은 사람이 있었다.
- **분자 모방**: 세균 항원과 몸의 항원이 비슷하면 공격받아 관절염 등.
- 합병증(★7): 길랭-바레, 반응성 관절염, 지사제 → 독성 거대결장·패혈증, 항생제 오래 → *C. difficile* 위막성 대장염, HUS. 소아에서 시프로는 쓸 수는 있으나 과거엔 잘 안 썼고 지금도 제한.
- 여시니아(★6): 감염 후 자가면역 → **관절염, 결절홍반** — IBD의 장외 증상과 비슷해 **IBD로 오인**될 수 있음. 돼지·들쥐·족제비 배설물 → **약수터 오염**(96년 조사에서 균이 많이 나옴).
- **장중첩증**: 세균성 장염으로 장이 부으면 회장이 대장으로 빠져 들어감(**회결장형**이 많음). **24시간까지는 풀어 주면 되지만 48시간이 지나면 수술 또는 천공**. 장간막 림프절 비대는 여시니아에서 뚜렷.
- 여담: **흑사병** = *Yersinia pestis* — 쥐 → 벼룩 → 사람. 14세기 유럽 인구 7500만 중 초기 5년에 2500만, 100년간 5천만 사망. 박쥐는 매개하지 않는다.

## 3. 진단과 항생제 (38:19–40:45)

- 병력(열, 혈성 점액변) → 예전엔 대변 WBC·**락토페린**, 지금은 **칼프로텍틴** → 문제가 있으면 예전엔 배양, **지금은 PCR**.
- 대변 도말: 면봉으로 슬라이드에 얇게 → **400배**로 WBC가 보이면 세균성(여시니아·아메바는 잘 안 나옴).
- 항생제를 쓰는 경우: **살모넬라 장염은 면역저하자·어린 영아**, **시겔라는 써야 함**, ***C. difficile*은 쓰던 항생제를 끊고, 계속되면 경구 반코마이신**, **여시니아는 패혈증일 때**, **캄필로박터는 이질(dysentery)·패혈증일 때**(가벼우면 저절로 낫는다).
- 쓰지 않는 경우: 바이러스, 식중독, 알레르기 장염, **O157(★9)**.
- 만성 설사: 감염 후 만성 설사, 약물, IBS, 유당불내증, 단장증후군, 선천성 거대결장 — "**감염 후에도 오래 갈 수 있다**".

## 4. 로타바이러스 (40:54–50:50)

- 예전 이름 **"가성 콜레라(pseudo-cholera)"** — 설사가 너무 많아서. 콜레라는 하루 8–10 L 설사 → 탈수·저칼륨혈증·심정지. **탈수 교정만 하면 콜레라도 로타도 죽지 않는다**. 로타는 **1세 전**에 심함.
- 미국은 병원이 비싸 슈퍼에서 ORS를 사서 밤새 먹이고, 인도·방글라데시는 NGO(UNICEF·WHO)가 ORS 공급. "우리나라는 로타로 죽을 일은 없다."
- 전파: **분변-경구**. 어린이집에서 기저귀 갈고 손 안 씻고 분유를 타면 다 걸림. 파리. 어른은 걸려도 무증상.
- **설사 기전**(★10): 융모 끝은 흡수, 움(crypt)은 분비("스프링클러처럼"). 끝이 날아가면 흡수 ↓·분비 그대로 → 설사 ↑, **lactase·이당류 분해효소 소실 → 이차성 유당불내증** → 쓸데없이 굶기지 말고 lactase 보충이나 **무유당** 분유. + **NSP4 독소**, **장신경계 자극**으로 장운동 ↑, 융모 위축으로 흡수 면적 ↓ — "설사가 생길 수 있는 모든 것이 다 겹쳐 있다."
- **ORS의 원리**: 콜레라 환자 대변의 Na·K·HCO₃ 비율대로 먹였는데 교정이 안 됐다 → **Na-포도당 공동수송**이 나중에 밝혀져 포도당을 조금 섞으니 Na가 흡수됨. **SGLT는 융모에 남아 있어** 로타에도 ORS가 흡수된다. 포도당을 너무 올리면 **삼투성 설사**.
- **음식 알레르기 악순환**: 점막 손상 → 투과성 ↑ → 분유 단백이 들어와 **T세포 감작** → 우유 알레르기 → 점막 손상 더 심해짐 → 이유식에도 알레르기.
- ORS 조성(★11): WHO ORS는 콜레라용이라 Na가 높다. **로타 대변의 Na는 콜레라의 절반 정도** → 국내 ORS는 Na를 낮게, **당은 2 g% 정도로 낮게**.
- 백신(★12): 두 가지 생백신.
