## 1. 수업 전 항생제 총정리 (00:01–10:00)

학생 요청으로 시작. "**이 정도만 알고 있으면 PK 때도 제 질문에 다 답할 수 있다**."

- **페니실린 + β-lactamase 억제제**: 암피실린/설박탐, 피페라실린/타조박탐, 아목시실린/클라불라네이트 → 단독보다 커버리지가 확 넓어짐.
  - 암피실린/설박탐: 그람양성 + 혐기균(+ 일부 그람음성).
  - **녹농균까지 덮는 페니실린 = 피페라실린/타조박탐**.
  - 설박탐은 단독으로도 *Acinetobacter* 에 약간 효과, 타조박탐 단독은 효과 거의 없음.
- **세팔로스포린**
  - 1세대(세파졸린): **그람양성, 특히 MSSA는 1세대가 3세대보다 낫다** → "3세대가 1세대보다 좋다"고 할 수 없다.
  - 2세대: 그람음성 쪽 보강. 3세대(세포탁심, 세프트리악손): 양성·음성 둘 다 어느 정도.
  - **녹농균을 덮는 세파 = 세프타지딤(3세대), 세페핌(4세대)**.
- **플루오로퀴놀론** (3가지만 외우기)
  - 시프로플록사신: 제일 먼저 개발, 그람음성·**녹농균에 가장 강함**, 혐기균 X. 녹농균이 시프로 S면 경구 시프로로 바꿀 수 있지만 요즘 내성 많음.
  - 레보플록사신: 녹농균·혐기균 모두 "중간치기(±)", **하루 1번**.
  - 목시플록사신: **혐기균 커버 → 복강내 감염**에 많이 씀, **UTI에는 못 씀**.
- **메로페넴**: ESBL *E. coli*·녹농균·혐기균 모두 → "지금으로서는 가장 강력".
- **CRE**: 세프타지딤/아비박탐, 세프톨로잔/타조박탐 (교수님 말씀 그대로 — 아래 「확인할 점」 참고).
- **MRSA**: 반코마이신, 테이코플라닌, 답토마이신, 리네졸리드 (답토·리네졸리드는 반코 내성에도).
- **테트라사이클린계**: 독시·미노·티게사이클린. 쯔쯔가무시에 독시. 티게사이클린은 내성균 일부 커버하지만 **정균** → 초기 중증 감염엔 잘 안 씀.
- **카바페넴**: 메로·도리·이미·에르타페넴 — **에르타페넴은 녹농균 X** (★2).

## 2. 면역저하 숙주의 감염 (15:00–33:16)

- **케이스(Claude가 만든 것)**: 68세 남자, AML 관해유도 항암 7일째 38.6℃, **ANC 180** → 어떤 항생제? (답은 뒤에서: 항녹농균 β-lactam — 세페핌, 피페라실린/타조박탐, 카바페넴)
- **기회감염** = 정상 숙주보다 **면역이 떨어진 숙주에 잘 감염을 일으키는 균**. 감염은 숙주 요인 약화 + 적당량의 균 + 환경이 맞아야 생긴다.
- 면역저하 숙주의 특징
  - 원인균이 매우 다양(*Candida*, *S. aureus* 등 몸에 있던 균도).
  - 염증 반응이 약해 **증상·징후가 약함** — CRP는 높은데 열은 잘 안 나는 환자도 있음.
  - **치료 기간이 길다**(정상인 5일이면 이들은 2주).
  - 사이토카인 매개 간접 효과, **환경(공기·물) 노출에 민감** → 모니터링.
  - 예방접종이 중요하지만 **효과는 떨어진다**.
  - **Net state of immunosuppression**: 면역억제제 양, 영양, 과거·현재 치료, 피부·점막 장벽 손상, 호중구·림프구 수, 면역글로불린, 기저 면역결함, 대사 상태(당뇨·간경화), 바이러스 감염을 **합쳐서** 판단.
- 원인 질환: 혈액암(골수 자체 + 항암), 조혈모세포이식(**환자의 조혈모세포를 강한 항암으로 다 없앤 뒤** 남의 세포를 넣음), 고형장기이식(내 면역세포는 그대로, **면역억제제** 때문), 자가면역질환(류마티스관절염·루푸스·강직척추염 → 항염증·면역억제제).
- **면역저하를 의심할 때**: 기저질환 없이 **같은 균·여러 균에 의한 감염이 반복**(코로나 → 독감 → 폐렴…) → **CBC, PB smear, HIV, 면역글로불린, 당뇨** 검사. 예: **Good syndrome**(흉선종 + 저감마글로불린혈증, 성인).
- **발열의 3대 원인**(보호자 설명용): ① 감염 ② 자가면역질환 ③ 암(림프종 등). 급성 발열은 감염이 80–90% → **감염부터 rule out**.
- 치료 원칙
  - "감염이 아닌 것 같다(성인 스틸병 같다)"며 항생제를 미루면 **큰일 난다** → **조기 경험적 치료**, **살균 항생제**.
  - 면역 회복이 늦어 치료 기간 연장.
  - **침습적 처치·검사 최소화**: 중심정맥관은 약 1주면 감염이 생긴다고 봄 → **매일 필요성 확인, 필요 없으면 제거**. (혈압이 떨어지면 중심정맥관을 잡는 이유: 승압제용 굵은 라인, CVP 측정)
  - 예방적 항생제는 일반적으로 안 쓰지만, **자가 조혈모세포이식 직후**(한 달간 WBC 거의 0)엔 **무조건** 쓰고 무균실(음압)에 둔다.
- 장기별 흔한 기회감염: 피부(칸디다, 아스페르길루스, HSV, VZV), 폐(녹농균, 결핵균·비결핵항산균, 노카르디아, **아스페르길루스·칸디다가 요즘 위험하게 떠오름**, 호흡기 바이러스), 위장관(**위막성 대장염**, **CMV 대장염 증가** — 혈변 + 내시경 CMV PCR 양성), 신경계(**리스테리아, 크립토코쿠스**).
- 실제 환자: 72세, 용혈성 빈혈로 **고용량 스테로이드** → **크립토코쿠스 수막염** → **암포테리신 B + 플루사이토신**(플루사이토신은 희귀의약품센터에서 구해야 함).

## 3. 항암치료 후 호중구감소성 발열 (33:16–53:30)

- **정의**: 구강 체온 1회 **≥38.3℃** 또는 **≥38.0℃ 1시간 이상**. 호중구감소 **ANC <500**, 심한 호중구감소 **<100**. (실제로는 37.5℃ 이상 + 오한이면 열로 봄. 역격리 1인실 급여도 ANC <500이어야 함)
- **기전**: 세포독성 항암제 → 점막(장벽) 세포 손상 → 균 침투. **위험인자 = ANC <500 + 점막염(mucositis)**.
- **시간 경과**: 항암 0일 → **7–9일째 nadir(가장 위험, 1주~열흘)**, **구강 점막염은 5일째쯤부터** 먼저 생기고 거기로 균이 들어와 발열 시작, **2–3주에 저절로 회복**. 회복 전까지 사망하기도 해서 이 시기엔 항생제를 깔고 가는 경우가 많다.
- 예방적 항생제는 **내성균 선택 압력**이 될 수 있다.
- **원인균(그람양성 vs 음성)**: 시기·기관·지역마다 다르다 — 2010년 자료는 그람양성이 많았고, 2025 체계적 고찰에선 기관마다 제각각. "**뭐가 많다고 하기 어렵다**".
- **경험적 항생제 선택 시 고려**: 중증도, 지역사회/병원 획득, 감염 부위·균 + **지역·기관 내성균 역학**(응급실 발열 환자 ESBL 20–30%면 → **카바페넴**), 과거 항생제·항진균제 노출(시프로 예방 중 발열이면 더 넓은 것), **집락(colonization) 과거력**(면역저하자는 CRE·VRE가 평생 갈 수도 → 패혈성 쇼크면 집락균까지 고려), **알레르기 과거력**("사고 나면 100% 병원 책임"), 신장·간 기능(용량 감량).
- **MASCC / CISNE 점수** (★3)
  - 직감보다 점수로 위험도를 매기는 것이 낫다. **21점 이상 저위험 → 경구 항생제, 외래 추적 가능**.
  - 교수님(권기태 교수님과 공저) 후향적 연구: 저위험 90%, 고위험 57%, **평균 70%가 외래로 봐도 됐다** → 그런데도 한국은 입원이 많다(산정특례 5%로 싸고 안심, 의사도 불안·소송 걱정). 원칙은 **점수 + 의사의 직감**.
- **경험적 항생제** (★4–6)
  - **세페핌, 피페라실린/타조박탐, 카바페넴**.
  - 아미노글리코사이드 + β-lactam 병용은 예전 방식, **요즘은 아미카신을 잘 안 씀**(부작용: **신독성, 청각장애**). 아미노글리코사이드를 쓰는 경우 — 심내막염(세프트리악손 + 젠타마이신), 결핵 4제요법 실패 시(아미카신·스트렙토마이신·카나마이신).
  - **반코마이신은 적응증이 있을 때만 추가**(예전엔 메로페넴 + 반코를 같이 쓰곤 했음).
  - 넓게 시작 → 배양 결과 보고 **de-escalation**.
- **재평가·지속 발열** (★7): 2–4일째 재평가. **4일 이상 발열 지속 → step-up 또는 진균감염 고려**. 요즘은 **CT로 진균 폐렴 확인 + galactomannan(아스페르길루스 항원)·β-D-glucan** → 양성 + CT 의심이면 **보리코나졸, 이사부코나졸, 리포좀 암포테리신 B**. 근거가 없어도 발열이 지속되면 **경험적 리포좀 암포테리신 B**(급여됨). 아스페르길루스 의심 → 보리코나졸 또는 암비솜. 레자펀진·포스마노게픽스는 국내 미도입.
- ***Candida auris***: 침습성, 치명률 높음 — 교수님 말씀으로 **2026년 3월 4급 법정감염병 신규 지정**, 국내는 독성 낮은 clade II가 주류였으나 clade I 검출 증가.

## 4. 이식 후 면역저하자의 감염 (1:04:41–1:16:19)

- 이식 후 감염 위험 = **수술 합병증 + 병원 내 노출 + 환자의 면역 상태**.
- 시기별: **초기 = 수술 관련 감염**, **중기 = 면역억제 최고조(가장 조심)**, **후기 = 면역억제제 사용에 따른 감염**.
- **고형장기 이식** (1개월 이내 / 1–6개월 / 6개월 이후)
  - **1개월 이내: 수술부위감염이 가장 많음**, 카테터, **흡인성 폐렴**(마취 → 수술 후 기침·폐활량계 불기).
  - **1–6개월: 면역억제제로 인한 기회감염** — CMV, PJP 폐렴, 아스페르길루스, 톡소플라스마 ("HIV 환자에서 잘 생기는 것과 비슷").
  - 6개월 이후: 면역억제제를 줄여 가지만 여전히 감염 잘 생김. **면역억제제는 평생 유지**.
- **조혈모세포 이식** (교수님 설명: 1개월까지 / 1–3개월 / 3개월 이후)
  - **Phase 1(생착 전)**: 전처치 항암(**conditioning chemotherapy**)으로 내 백혈구가 0, 점막 손상 → **무균실**. 칸디다·세균 → **포사코나졸(녹사필) 등 항진균제 예방**, 항생제·항바이러스제(시프로, 메트로니다졸 등)를 깔고 감.
  - **Phase 2**: 호중구는 회복되지만 **세포성 면역 심각 저하** + **GVHD(이식편대숙주반응)** — 피부가 다 벗겨지거나 독성 간염(OT/PT 수천)으로 사망하기도. **BK virus → 출혈성 방광염**, 치료제 거의 없음.
  - **Phase 3**: 생착이 완전하면 **면역억제제를 끊을 수 있다**(고형장기와 다름) → **예방접종을 처음부터 다시**(접종력이 0으로 리셋). (★9 사백신/생백신 시기)
- **두 이식 비교**: 고형장기 = 면역억제제 평생, 초기 수술·원내 감염, 후기 위험은 이식편 기능·거부반응 치료 강도에 좌우 / 조혈모 = 면역억제제 점차 중단(GVHD 없으면), 초기엔 호중구 없음, 세포성·체액성 모두 저하. **CMV 재활성화·아스페르길루스는 둘 다 위험**.
- **예방**
  - **PJP**: 셉트린(TMP/SMX)을 길게. **스테로이드 프레드니솔론 기준 20 mg 이상 4주 이상이면 무조건 셉트린**.
  - **CMV**: 조혈모이식 환자는 초반 2주마다 외래에서 **CMV RQ-PCR** → 증상이 없어도 오르면 **선제적(preemptive) 간시클로비르**(증상이 늦게 나타나 나빠지면 치료 못 할 수도).
  - 항진균 예방: 조혈모이식, 폐이식 등 고위험군 (본원은 폐·심장 이식 안 함; 폐이식 5년 사망률 50% 이상).
  - 예방접종: 이식 **전 생백신 완료가 원칙**이지만 실제로는 이미 면역저하·암 치료 중이면 **생백신 금기**라 잘 못 함. 이식 후엔 **사백신 위주 재접종**. (예전 신장이식 전 대상포진 생백신 연구가 있었지만 지금은 사백신이 있어서 해당 없음)

## 학습자료(필기본 2025)와 다른 점·확인할 점

1. **조혈모세포이식 시기 구분**: 수업에선 "1개월 / 1–3개월 / 3개월 이후"라고 했지만, 필기본 표(Harrison Table 138-2)는 **<1개월 / 1–4개월 / >6개월**. 시험은 강의자료 표 기준일 가능성이 높으니 표를 우선.
2. **지속 발열 → 항진균제 시점**: 수업 "**4일 이상**", 학습자료 "4–7일". 같은 맥락(4–7일 범위의 시작)으로 보면 된다.
3. **CRE 약**: 교수님은 세프톨로잔/타조박탐과 세프타지딤/아비박탐을 같이 말했는데, 교과서 기준으로 **CRE(KPC 등)에 쓰는 건 세프타지딤/아비박탐**이고 세프톨로잔/타조박탐은 주로 **다제내성 녹농균** 약이다. 문제에 나오면 보기 문장을 잘 볼 것.
4. **경험적 항생제 시작 시간**(학습자료: 1시간 이내)은 이번 수업에서 따로 언급 없음.
5. **생착 기간**: 수업 "1–2개월" — 보통 2–4주로 알려져 있으니 숫자보다 "생착 전 = 호중구 0, 무균실"이라는 흐름으로 기억.
