## 1. 정의와 정상·비정상 (00:12–03:41)

- 교수님 목에도 평생 같이 가는 림프절이 하나 있다 — 만져진다고 다 병이 아니다.
- **림프절염** = 염증 / **림프절병증(lymphadenopathy)** = 커진 것. 커지는 기전 3가지: **세포 증식, 종양세포 침윤, 이물질 침착**.
- 림프절 분포: 목, 가슴, 팔오금, 서혜부, 오금 — "옛날 시험에 낸 적 있다" → **목이 제일 많다**. 활차상·오금은 임상적으로 잘 없음.
- **1차 의료기관에선 악성 1% 미만**, 칠곡경북대병원 같은 의뢰 병원에 온 환자는 **16%**.

## 2. 원인 질환 (03:46–08:04)

- **감염이 제일 많고, 그중 바이러스가 세균보다 훨씬 많음**. 세균성 림프절염은 요즘 드묾 — 의료 접근성이 좋아 연조직염·편도염·편도주위 농양 단계에서 다 병원에 오기 때문. 세균 감염은 **국소**(연조직염 → 서혜부, 편도주위 농양 → 목).
- **결핵**: 국내에 많은 이유 = **6·25**(영양 불량, 피난·집단생활 → 잠복결핵) → 나이 들어 재활성. 요즘은 잠복결핵 치료로 줄어듦. **국소**(쇄골상·목)로 잘 옴.
- 바이러스: **전신**(특히 **급성 HIV 증후군**). 자가면역: 대체로 **전신**. 약물: **전신**.
- 악성: **혈액암(백혈병·림프종) = 전신**, **고형암(폐·유방·갑상선) = 배액 부위, 같은 쪽(동측)** — 겨드랑이면 유방암, 갑상선도 오른엽·왼엽 각각.
- 부위로 **전신 질환 vs 국소**, 국소면 **악성 vs 감염(결핵 vs 바이러스)** 을 가른다.

## 3. 임상 평가 (08:04–15:09)

- 증상: 상기도면 상기도 감염 증상. **림프종: 열이 많이 오래, B 증상(야간 발한, 체중 감소)**, 호지킨은 가려움. HIV → 성생활, 쯔쯔가무시 → 진드기, 약물력.
- 나이(★5). 크기(★4). 촉진(★7).
- **간·비장이 같이 커지면 전신 질환**(망내계) — 감염성 단핵구증, 백혈병, 림프종.
- 경부 림프절 + 흡연 + 고령 → **설암·비인두암 등 두경부암 검진**.
- **전신 = 떨어진 부위 3개 이상**(목, 액와, 서혜부).
- **목**: 흔한 양성 = 상기도 감염 / 악성 = 두경부암·유방암·폐암·갑상선암 / **결핵** — 이 **세 가지**로 보고 히스토리를 맞춰 들어감.
- **액와 = 유방암**, **서혜부 = 연조직염·성매개 감염(매독)**, 악성이면 골반 쪽 종양.
- 흉부·복부 림프절은 CT에서 우연히 또는 전신 림프종 의심으로. 호흡기 증상 동반 → **폐암·폐결핵**, 젊으면 **사르코이도시스·감염성 단핵구증**, **고령이면 암**.

## 4. 검사 (15:16–18:05)

- 가정의학과 연구(1차 의료): **절반은 검사 안 해도 됨**, 생검은 3%.
- 기본: **CBC, EBV·CMV 항체, 자가항체, 흉부 X선** — 처방 세트로 묶어 둠.
- 영상: CT·MRI를 많이 씀(초음파는 사람 손이 필요해서). 초음파 **장축/단축 비 <2.0(둥글수록) → 악성 가능성**.
- **PET-CT는 첫 평가에 안 함** — 종격동·복강 내라 진단 수술이 부담될 때, 또는 FUO처럼 오리무중일 때 생검 목표를 찾으려고. **골수생검은 처음부터 하지 않고**, 림프절 생검으로 림프종이 나오면 골수 침범 확인용.

## 5. 생검과 관리 (18:09–24:19)

- 즉시 생검(★8). 두경부암 의심 → **이비인후과**(비인두·비강·혀·편도·갑상선 생검).
- 젊고 상기도 감염 후 1주쯤 커졌다 → "**보통 그냥 봅니다**"(CBC 정도는 가능).
- 생검(★9): FNA는 쉽지만 세포 모양만 봐서 정확도 ↓ / 절제 생검은 통째로 → 가장 정확, 부위에 따라 어렵고 합병증 위험 / **core는 생검 총(gun)으로 조직을 뜯어냄 — 대안**. 림프종은 **CD 특수염색으로 클론성** 판단.
- 생검 필요 예측 모형: **40세 초과, 쇄골상, 2.25 초과, 딱딱함** / 최근 이비인후과(상기도) 증상은 생검 불필요 쪽 — 해리슨 내용.
- 관리(★10·11): 진단이 되면 NSAID로 지켜볼 병 / 염증성 질환은 스테로이드·면역조절제 / 림프종은 항암 / 고형암은 수술·항암·방사선. 소아는 항생제 시도 가능하다고 Cecil에 있지만 **소아도 항생제 과다 사용이 문제**.

## 학습자료(필기본)와 다른 점·확인할 점

1. **나이 기준**: 수업 "**50세**가 넘으면 악성 ↑"(병력) + "**40세**가 넘고…"(생검 예측 모형) 두 숫자가 다 나왔다. 학습자료도 "나이 >40(50)". 예측 모형 문제면 40, 일반 병력이면 50.
2. **크기 단위**: 수업 "2.25를 초과"라고만 했다 — 학습자료 기준은 **2.25 cm²(넓이, 1.5 × 1.5 cm)**. 지름 2 cm와 헷갈리지 말 것.
3. **추적 간격**: 수업 "**2–4주** 추적관찰"(정리 슬라이드), 즉시 생검이 아닌 경우 "**2주 정도** 미룰 수 있다"(18:53) — 같은 맥락.
4. **증례**: 교수님이 올해도 "케이스 2개"라고 했다. 학습자료 7단원의 작년 증례 2개(**감염성 단핵구증 → EBV 항체검사** / **흡연 고령 + 딱딱한 경부 림프절 → 즉시 생검**)가 그 꼴이다.
5. 쇄골상 림프절 원인 목록에 "공안암"으로 들린 말이 있다(12:13) — 학습자료 목록(폐·유방·위장관·후복막·고환·난소암, 결핵 등)으로 보면 **고환암**으로 보인다(srt는 그대로 둠).
