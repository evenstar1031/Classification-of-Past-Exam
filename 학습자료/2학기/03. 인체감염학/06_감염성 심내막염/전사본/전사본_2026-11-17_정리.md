## 1. 심장 구조와 정의 (00:23–05:44)

- 판막 4개(승모판·대동맥판·삼첨판·폐동맥판) = "**대문 역할**". 심장벽: 벽측·장측 심낭 → 심근 → **심내막(내피 + 결합조직)**.
- 감염성 심내막염 = 판막·심방실 안쪽(이상이 있든 없든)의 미생물 감염. 대부분 **세균**, 드물게 리케차·클라미디아·진균.
- **병태생리**: 내피 손상(외상, 난류, 대사 변화) → 혈소판·피브린 침착(**비세균성 혈전성 심내막염**) → 점막 손상으로 구강균이 **균혈증** → 그 자리에 **부착·집락** → 혈소판·피브린·호중구가 더 엉겨 **증식체(vegetation)**.

## 2. 위험인자와 원인균 (05:44–11:03)

- 옛날 = **류마티스 심장병**(개발도상국). 요즘 = **IV 약물 사용자**, 노화에 따른 **퇴행성 판막 질환**, **인공판막**, 심장 내 기구, 선천성 심장병, 카테터.
- 선진국 자기 판막 심내막염의 **약 30%가 의료 관련**, 전체의 **최대 30%가 인공판막 심내막염**.
- 균이 들어오는 길: **치과 감염(가장 전형적)** — 점막이 노출되는 시술 후 일시적 균혈증, 요로감염, 피부, 폐.
- 원인균(★6). **HACEK** = 심내막염을 일으키는 그람음성 구간균 5가지: *Haemophilus*, *Aggregatibacter*, *Cardiobacterium*, *Eikenella*, *Kingella* — "수업 시간에도 계속 해케라고 할게요".
- TAVI 동영상: 대퇴동맥으로 판막 달린 카테터를 넣어 기존 대동맥판을 밀어내고 자리 잡음(★7).

## 3. 임상양상 (11:03–15:28)

- 증식체 일부가 떨어져 → **뇌색전·뇌졸중, 전신 색전**. 혈관염·면역복합체 → **결막하 출혈, 점상출혈, 손톱 밑 선상 출혈(splinter)**. 이런 소견은 빈도가 낮다(2–5%, 10%…).
- 판막 파괴 → 다 안 닫힘 → (승모판이면) 좌심실 수축 때 **좌심방으로 역류** → "럽덥 사이에 잡음" = **심잡음**(★1).
- 말초 소견: **Osler 결절, Janeway 병변, Roth 반점**, 점상출혈, 선상 출혈 — 실제로 "그렇게 많이 발견되는 경우는 아니다".

## 4. 진단 (15:28–28:03)

- 혈액배양 1세트 = 호기·혐기 병 한 쌍. 예전엔 다른 부위에서 3세트였는데 지금은 **전형적 균이면 2세트**(★2).
  - 자기 판막 전형적 균: ***S. aureus*, *S. lugdunensis*, *E. faecalis*, 연쇄구균(폐렴알균·화농연쇄구균 제외)**, HACEK.
  - 인공판막이 있으면 + **CoNS**, 세라티아, 녹농균, *Cutibacterium acnes*, NTM 등 ("피부 상재균인데 갑자기 기억이 안 난다" — 코리네박테리움으로 보인다).
- **병리 기준**: 수술에서 증식체(균·피브린·혈소판·호중구) 또는 농양 확인 = 확진.
- 주요 기준(★3): ① **미생물** — 전형적 균 2세트, 배양 안 되는 세포내균(***Coxiella burnetii*, *Bartonella***)은 **PCR 또는 항체가** ② **영상** — 초음파·CT의 증식체, 판막 천공·동맥류·농양·가성동맥류·누공, **새 역류**, 인공판막 **탈락(dehiscence)**, **PET-CT 대사 활성**(새로 추가) ③ **수술 소견**.
- 부 기준: 소인(과거 심내막염, IV 약물, 인공판막, 선천성 심장병), **발열**(다른 원인 없이), **혈관 현상**(색전, 경색, 진균성 동맥류 — 혈관 분지점, 결막 출혈, Janeway, 뇌·비장 농양, 자반), **면역 현상**(사구체신염, Osler, Roth), 전형적이지 않은 균의 반복 배양, **3개월 이내 PET-CT 이상**, **청진상 새 잡음**(★4).
- **배양음성 심내막염**: 배양 어려운 비정형균·진균, 그리고 **동네에서 항생제를 애매하게 쓰고 온 경우**.
- 진단 노력: 혈액배양 **가능하면 3세트, 각각 다른 정맥, 충분한 양**. **48–72시간 음성이면 2세트 추가**. 안정적 아급성이면 배양 결과까지 항생제 보류 가능하지만 "**실제 임상에서 이렇게 하는 사람은 없다**". 패혈증·활력징후 악화면 3세트 채취 후 바로 경험적 항생제.
- 보조 검사: CBC, ESR, CRP, 보체, RF ↑. X-ray(폐색전, 폐부종), EKG(허혈, 전도 지연, 부정맥 — 드묾).
- **심초음파가 가장 중요**: 처음 의심 → **TTE**(가슴벽 앞에서), **인공판막·심장 내 합병증·TTE가 불충분할 때 → TEE**(위내시경처럼 식도 뒤에서, 가려지는 구조물). 신경 증상이 있으면 **뇌 MRI**, 척추도 **spine MRI**. 알고리즘(★5) "해리슨 표이고요. **중요하죠**."
- TEE 사진: 빈 공간에 큰 이물질(증식체)이 혈류 따라 왔다 갔다. 도플러에서 들어오는 피 파랑·나가는 피 빨강, 역류가 있으면 **색이 섞인다**.

## 5. 치료 (28:03–38:19)

- **다학제**(감염내과, 심장내과, 흉부외과, 영상의학과). 목표: 균 제거, 합병증 예방, 구조적 손상 교정.
- 실제 환자 이야기: 원인 모를 열 + CT 색전성 경색 → 청진에서 잡음 → 초음파 → "떨어져 나가면 뇌경색·비장경색·장 허혈, 판막이 너덜너덜해서 **심정지**까지 올 수 있다"고 설명하고 돌아섰는데 실제로 심정지 — "**조기 진단·판단이 중요**".
- 경험적 항생제(★9). 해리슨(미국) 기준이라 국내 가이드라인과 다르다 — "**추가 자료를 드릴게요**".
- 확정 치료(균이 나온 뒤) — "**이거를 외우라는 것은 아니에요**. 감염내과·흉부외과 하시면 그때 알면 되는 거":
  - 연쇄구균: 페니실린 감수성(MIC 낮음) → **페니실린 또는 세팔로스포린 단독**(알레르기면 반코). MIC **0.12–0.5 미만** → 페니실린 4주 + **젠타마이신 2주**(시너지). 내성 → 둘 다 **6주**.
  - 장알균: **암피실린 + 세프트리악손** — 세프트리악손은 장알균에 내성인데 왜? **시너지** 때문. 또는 페니실린 + 젠타.
  - **MSSA: 나프실린·옥사실린·플루클록사실린**(가벼우면 세파졸린) / **MRSA: 반코마이신·답토마이신** / 인공판막 MSSA: 나프실린 + 젠타 + **리팜핀(항바이오필름)**, MRSA면 반코 + 젠타 + 리팜핀.
  - HACEK, *Coxiella*, *Bartonella* — "다 외우기는 어렵겠죠".
- 수술(★11): 반드시 필요한 경우 — **심부전, 판막 기능 이상으로 쇼크, 농양·누공·방실 차단**(약만으로 어려움), **7–10일 써도 균혈증 지속**, 항생제만으로 부족한 균, **불안정한 인공판막(틈이 벌어짐)**, **심장 내 기구는 전체 제거**. TAVI/TAVR는 적응증이 50–80%여도 고령이라 **실제 수술 빈도는 낮다**.
  - 시기: **즉시** — 쇼크, 심장 파열 / **1–2일 내** — 심부전, 효과적 항생제 없음, 증식체 >1 cm + 심한 판막 이상, 움직이는 증식체 >3 cm / **선택적** — 안정적이고 역류가 천천히 늘 때. 항생제 실패·진균 감염도 수술.
- **부분 경구 치료(POET, NEJM)**: 예전엔 4–6주 입원 주사. **안정적인 좌심 IE 400명**, 정맥 **10일** 뒤 경구 전환 → 결과가 나쁘지 않았다(통계적 차이 없음). **바이어스: 좋아질 사람만, MRSA 같은 위험균 제외**. 그래도 "아주 훌륭한 시도" → 가이드라인이 대폭 바뀌는 계기.

## 6. 합병증·인공판막·예방 (38:19–44:44)

- **색전이 최대 40%**. 위험: **증식체가 클수록**, **좌측**(바로 전신 순환), **진균, S. aureus, S. bovis**. 항생제 사용 후 급격히 줄었지만 계속 의심. 부위: 뇌경색, 심근경색, 폐색전, 비장·신장 경색, **진균성 동맥류**(혈관 분지점 벽을 약하게 → 출혈로 변함·파열).
- 국소 확산: 심부전, 누공, **판막 주위 농양**. 전이성 감염(혈행성): 피부, 비장, 신장, 뼈(척추염). 면역 반응. X-ray 폐부종 사진.
- 인공판막(★6·7).
- 예방 대상: **과거 심내막염, 인공판막, 좌심실 보조장치·이식형 인공심장, 교정 안 된 청색증 선천성 심장병, 심장 이식 후 판막병증** — 난류·내피 손상 고위험. 약(★10): 경구 불가 → **암피실린 주사**, 페니실린 알레르기 → **세팔렉신, 클라리스로마이신, 아지스로마이신, 독시사이클린**, 알레르기 + 경구 불가 → **세파졸린, 세프트리악손**.
- **ESC 2023**: TAVI/TAVR 환자도 **고위험군에 명시**. 정맥 **2주** 후 안정적이고 고위험 다제내성균이 아니면 **외래에서 경구 또는 주사 연장 가능**(전환 전 합병증 없음 확인). **PET-CT·심장 CT·혈관조영**이 가이드라인과 Duke 기준에 들어감.

## 학습자료(필기본)와 다른 점·확인할 점

1. **Osler vs Janeway 통증**: 수업 15:03–15:14에서 "오슬러 노드는 혈관염 원리, **통증이 없습니다** / 제인웨이는 색전·면역복합체… 여기 통증이 있고 여기 통증이 없습니다"라고 말이 엉켰다(슬라이드를 가리키며 말한 듯). 학습자료와 교과서 기준은 **Osler = 아픔(혈관염, 연쇄구균, 아급성) / Janeway = 안 아픔(색전, 포도알균, 급성)** — "O = Ouch". 시험은 이쪽으로.
2. **Janeway의 기전**: 수업 "색전·면역복합체 반응", 학습자료 "**색전**"(면역은 Osler·Roth). Duke 부 기준에서도 Janeway는 **혈관 현상**, Osler·Roth는 **면역 현상**.
3. **TTE/TEE 말실수**: 25:06, 25:47, 26:02에서 "TTE"를 "TEE"로 말했다(앞뒤 문맥상 저위험군은 먼저 TTE). srt에서 바로잡았다. 알고리즘은 학습자료 그림대로.
4. **인공판막 원인균 시기**: 수업은 "1년 이내 CoNS·S. aureus, 1년 이후 자기 판막과 비슷"만 말했다. 학습자료 표(해리슨 22판)는 **<2개월 / >12개월 / TAVR-PVE** 세 줄.
5. **경험적 항생제 국내 기준**: "추가 자료를 드리겠다"고 했다 — 받으면 학습자료에 보충할 것.
6. 인공판막에서 전형적 균 목록 중 교수님이 "**클로스트리디움**"이라고 했는데, 학습자료 목록에는 없고 ***Corynebacterium striatum/jeikeium*** 이 있다(바로 뒤에 "피부 상재균인데 기억이 안 난다"). srt에서는 말한 대로 두었다.
7. 예방 항생제 시점: 수업 "시술 1시간 전" = 학습자료 표 "1시간 전"(세팔로스포린 주사는 30분 전).
