# 0. 이 수업을 공부하는 법

**홍성욱 교수님**(경북대학교병원 마취통증의학과)의 「특수마취관리 — 외래/진정」 수업이다. 특수마취 중에서도 **의식진정**(conscious sedation) 하나만 다룬다. 필기자 말대로 강의는 빠르고 설명이 많이 생략됐지만, 약물 수가 많지 않고 금식시간은 다른 마취과 수업에서도 반복해서 강조한 내용이라 **공부할 양이 많지 않은 수업**이다.

2부의 기출 14문항(2020–2025, 2022년 2문항은 필기본에서 옮김)은 네 유형으로 거의 고정되어 있다.

| 유형 | 2부 문항 | 묻는 방식 |
|---|---|---|
| **진정 4단계 구분** — 매년 1문항 | 1·5·8·12·13번 | 강의록 문장을 그대로 주거나, 사례(수면내시경 환자)에 적용 |
| **Ketamine** | 2·6·9·14번 | 특징 목록을 주고 약물 맞히기, 또는 "눈 뜨고 멍하니, 혈압·맥박 상승" 사례 |
| **가장 많이 쓰는 조합 = Remifentanil + Propofol** | 4·7번 | 조합 고르기, 또는 "250분 주입 후 25분 만에 깸" 사례 |
| 번외: 금식시간, Midazolam | 3·11번 | 우유 6시간 / short acting BZ + flumazenil |

10번(2021, 소아마취)은 이 수업으로 분류되었지만 필기본에는 없는 내용이라 맨 끝(9단원)에 따로 정리했다.

!!! key "핵심"
    - **진정 4단계의 강의록 표현을 그대로 외운다.** 구분하는 열쇠는 "무엇에 반응하는가"(구두 명령 / 가벼운 접촉 / 반복·통증 자극)와 "기도 처치가 필요한가"다.
    - **Ketamine 슬라이드 3장**(특징, 금기·장점, 부작용)은 문제 지문으로 거의 그대로 나온다.
    - **역전제(reversal agent)가 있는 정맥 진정제는 두 개뿐**: Midazolam ↔ Flumazenil, Opioid ↔ Naloxone. Midazolam 문제는 이것만 알아도 풀린다.

# 1. 의식진정이란

환자가 시술이나 처치, 간단한 수술을 받을 때 불안해하면 환자도 괴롭고, 시술자에게도 부담이 된다. 그래서 **전신마취에 이르지 않을 정도로 환자를 잠시 재우는 것**을 의식진정이라고 한다. 수면내시경이 대표적인 예다.

## 정의: 4단계

진정은 깊이에 따라 네 단계로 나눈다. 다만 단계가 **딱 떨어지는 것은 아니고**, 환자가 두 단계 사이 어딘가에 있을 수도 있다(아래 sedation continuum).

| 단계 | 의식·반응 | 기도·환기 | 심혈관계 |
|---|---|---|---|
| **최소 진정**(Minimal sedation, Anxiolysis) | **불안이 해소된 상태**. **구두 명령에 반응**. 인지 기능과 조정 기능은 저하 | 영향 없음 | **영향을 받지 않는다** |
| **중등도 진정**(Moderate sedation) | **의식이 저하된 상태**. **구두 명령 또는 가벼운 접촉 자극에 반응** | 기도 유지를 위한 **어떠한 처치도 필요 없고**, 자발적인 환기도 유지 | 대개 유지 |
| **깊은 진정**(Deep sedation) | **쉽게 깨지는 않으나 반복되는 자극이나 통증 자극에 반응** | 기도 유지를 위해 **도움이 필요할 수 있고**, 자발 환기가 **부적절할 수 있다** | 대개 유지 |
| **마취**(Anesthesia) | 전신 마취, 척추 마취, 일부 부위 마취를 의미 | — | — |

- **최소 진정 vs 중등도 진정**: 최소 진정은 의식이 떨어지지 않고 불안만 풀린 상태(말에 정상적으로 대답한다). 중등도 진정은 "의식이 저하"되었다는 말이 들어간다.
- **중등도 vs 깊은 진정**: 반응하는 자극이 "말·가벼운 접촉"이면 중등도, "반복 자극·통증 자극"이면 깊은 진정. 기도에 손을 대야 하면(삼중기도확보법, jaw thrust 등) 깊은 진정이다.
- 시술자는 '깊은 진정'을 노렸는데 진정이 점점 깊어져 **전신마취에 준하는 상태**가 되기도 한다. 그래서 진정이라도 전신마취처럼 준비하고 감시한다(2·3단원).

!!! exam "기출 포인트"
    매년 한 문제씩 나왔다. 8·12·13번은 위 표의 강의록 문장을 그대로 주고 단계를 고르게 했다(8번 깊은 진정, 12번 최소 진정, 13번 중등도 진정). 1번은 "의식 저하 + 구두 명령·가벼운 접촉에 반응 + 기도·환기 유지" 사례 → 중등도 진정. 5번은 "이름을 불러도 반응 없고, 세게 흔들어야 움직이고, 삼중기도확보법을 해야 환기됨" 사례 → 깊은 진정(혈압이 떨어진 것은 미끼). 보기의 'Anxiolysis', '수면유도 상태', '부분 마취'는 함정이다 — Anxiolysis는 최소 진정의 다른 이름이다.

!!! memo "암기"
    구두 명령 → **최소** / 구두 명령 **또는 가벼운 접촉** + 기도 처치 불필요 → **중등도** / **반복·통증 자극** + 기도 도움 필요할 수 있음 → **깊은** / 통증에도 안 깸 → **마취**

## Types of Sedation — 진정의 연속선(sedation continuum)

진정은 크게 4단계로 나누지만, 실제로는 약을 더 줄수록 환자의 행동과 반응이 연속적으로 변한다. 필기본의 그림을 순서대로 옮기면 다음과 같다.

| 깊이 | 필기본 표현 | 뜻 |
|---|---|---|
| 얕음 | Alert-anxious | 깨어 있고 불안함 |
| | Alert-calm (anxiolysis) | 깨어 있고 차분함 |
| | Drowsy but clear mentation (sedation) | 졸리지만 정신은 맑음 |
| | Eyes open, speech slurred | 눈은 뜨고 말이 어눌함 |
| | Eyes closed but answers questions appropriately | 눈은 감았지만 질문에 적절히 대답 |
| | Opens eyes to voice, is confused | 부르면 눈을 뜨지만 혼동 |
| | **Oxygen desaturation on room air** | 실내 공기에서 산소포화도 저하 |
| | Opens eyes to pain, responds purposefully | 통증에 눈을 뜨고 의도적으로 반응 |
| | Eyes closed, moans and withdraws from pain | 눈 감고, 신음하며 통증을 피함 |
| | Moans to pain, nonspecific motor response to pain | 통증에 신음, 비특이적 운동 반응 |
| | **CO₂ retention** | 이산화탄소 저류 |
| | **Oxygen desaturation on 2 L O₂** | 산소 2 L를 줘도 포화도 저하 |
| | No response to pain | 통증에 무반응 |
| | Bradypnea, poor gag reflex | 느린 호흡, 구역반사 약화 |
| | **Apnea, hypotension** | 무호흡, 저혈압 |
| 깊음 | Death | 사망 |

의식이 떨어지는 것과 함께 **호흡 문제(산소포화도 저하 → CO₂ 저류 → 무호흡)가 먼저, 순환 문제(저혈압)가 나중에** 나타난다는 흐름을 보면 된다. 그래서 진정에서 가장 신경 쓰는 것이 기도와 호흡이다(8단원).

## 목표(Goals)

한마디로 **불편을 느끼는 환자를 안정시키고, 시술자는 편안하게 시술할 수 있게 하는 것**이다.

- **환자의 안전과 평안을 유지**하기 위함
- 신체적 불편, 통증, 불안을 최소화하기 위함
- 마취·진정제를 투여하는 동안 부적절한 반응을 최소화하기 위함
- **시술하는 동안 환자의 행동을 통제**하기 위함
- 소아나 의사소통이 어려운 성인에서 신속하면서도 불편하지 않게 목적한 시술을 수행하기 위함
- 약속된 기준에 의해 환자의 안전한 **퇴원(외래환자) 또는 퇴실(입원환자)**이 이루어지도록 하기 위함

# 2. 진정 전 평가(Pre-Sedation Evaluation)

**진정 전 평가는 전신마취에 준해서 똑같이 한다** — 평가, 검사(lab), 상담(counseling).

- **진정전기록지** 작성
- **관련 병력**(relevant history)
- **집중 신체 진찰**(focused physical examination) — 심장, 폐, 기도
- **검사실 검사**(laboratory testing)
- **진정 전 소견**(findings before sedation) 기록
- **상담**(counseling) — 위험(risk), 이득(benefit), 한계(limitation), 대안(alternatives)을 설명

## 병력(History)

과거력, 현재 복용 약 등으로 **환자의 신체 상태**(physical status)를 파악해, 합병증 위험이 높은 환자를 가려낸다.

- **과거력**(past history) — 이전 진정·마취 경험과 그때 문제가 있었는지
- **현재 전반적인 건강 상태**(current state of general health)
- 안전에 영향을 줄 수 있는 **관련 신체 소견**(any pertinent physical findings)
- 알려진 **약물 반응**(known drug reactions)

## 신체 진찰(Physical Examination) — ABC

마취에서 가장 문제가 되는 것은 **기도 확보**다. 전신마취 때는 기관삽관을 하고 기계환기를 하므로 괜찮지만, **진정은 삽관을 하지 않으므로 기도 개방성**(airway patency)**을 확실히 평가**해야 한다. 진정약물이 중추신경계를 억제하면서 호흡과 심혈관계도 억제해 **저산소증**(hypoxia)을 일으킬 수 있기 때문이다.

- **A — 기도 개방성**(airway patency)과 기도 보조가 필요할지
- **B — 호흡 양상과 호흡음**(breathing pattern and breath sounds)
- **C — 심혈관 진찰**: 심음과 말초 관류(distal perfusion)
- 병력상 문제가 의심되면 **다른 장기 계통**도 진찰한다.

평소 **수면무호흡**(sleep apnea)이 있는지, **기도 확보가 어려운**(difficult airway) 환자인지, **경추**(C-spine) 문제가 있는지, CO₂가 쌓이거나 산소가 떨어질 때 심폐 기능에 어떤 영향이 올지, 기저질환이 있는지를 충분히 평가해야 한다.

## ASA 신체 등급(ASA Physical Status)

전신마취와 **같은 등급 체계**를 적용한다.

| 등급 | 정의 |
|---|---|
| I | 건강한 환자 |
| II | 경도의 전신 질환, 기능 제한 없음 |
| III | 활동을 제한하지만 무력화하지는 않는 중증 전신 질환 |
| IV | 생명을 지속적으로 위협하는, 무력화하는 전신 질환 |
| V | 수술을 하든 안 하든 24시간 생존이 기대되지 않는 빈사 환자 |

**ASA III 이상**이면 예정된(elective) 진정 전에 **기도·진정 전문가와 상의**한다.

## 상대적 금기증(Relative Contraindications)

| 금기증 | 이유 |
|---|---|
| **위식도역류**(GERD) | **흡인 위험**. 진정약물로 구역반사(gag reflex)가 약해져 위 내용물이 식도로 역류해 기도로 흡인될 수 있다 |
| 삼킴 이상이 있는 뇌성마비 | 흡인 위험 |
| 무호흡, 수면무호흡, 코골이 병력 | 진정 중 상기도가 쉽게 막힌다 |
| **목 불안정성**(neck instability) — 골형성부전증(osteogenesis imperfecta), 다운증후군 | 기도 확보를 위해 **삼중기도확보법**(triple airway maneuver)을 할 때 **목을 젖혀야** 하므로, 경추 불안정성이 있는지 평가해야 한다 |
| 조절되지 않는 경련 질환 | |
| 중대한 **심폐** 질환 | 신체 진찰 단계에서 말했듯 심폐 기능이 중요하다 |
| **악성고열증**(malignant hyperthermia) 병력 | 사용하는 약제에 따라 생길 수 있어 과거력이 중요하다. 특정 마취 약물에 유전적으로 민감한 환자가 노출되면 급격한 체온 상승, 근경련(근강직), 다장기부전이 생기는 치명적인 희귀 합병증이다 |
| 응급 상황에서 정맥로 확보가 어려울 것으로 예상 | 문제가 생겼을 때 약을 줄 길이 없다 |

## 진정 전 금식(Pre-Sedation Fasting)

금식은 **전신마취에 준해서** 한다.

| 섭취한 것 | 최소 금식 시간 |
|---|---|
| **맑은 액체**(clear liquids): 물, 과육 없는 과일 주스, 탄산음료, 맑은 차, 블랙커피 | **2시간** |
| **모유**(breast milk) | **4시간** |
| **영아용 분유**(infant formula) | **6시간** |
| **비인간 우유**(nonhuman milk, 일반 우유) | **6시간** |
| **가벼운 식사**(light meal): 토스트와 맑은 액체 정도 | **6시간** |

- 일반 우유는 **위 배출 시간이 고형식과 비슷**하므로 마신 양을 고려해 금식 시간을 정한다.
- 튀기거나 기름진 음식, 고기가 들어간 식사는 위 배출이 더 느리므로 음식의 양과 종류를 함께 고려한다(교과서 기준으로는 보통 8시간).

다음 상태에서는 위 내용물 흡인 위험을 줄이기 위해 **금식을 더 길게** 할 수 있다.

- **위식도역류**(gastro-esophageal reflux)
- **식도 운동 장애**(esophageal dysmotility)
- **위 배출 장애·지연** — 당뇨병, 임신 등
- **알려진 또는 의심되는 기도 문제**

# 3. 진정 중 감시·장비·기록

## 감시(Monitoring)

기본은 환기(ventilation), 산소화(oxygenation), 심혈관계를 볼 수 있는 **심전도**(EKG), **맥박산소측정기**(pulse oximetry), **비침습적 혈압**(NIBP)이다. 요즘에는 뇌파를 분석해 진정 정도를 숫자로 보여 주는 **BIS** 등 여러 기계를 쓰기도 한다.

| 감시 대상 | 방법 |
|---|---|
| **의식 수준**(level of consciousness) | 명령이나 자극에 대한 반응. BIS 등 |
| **환기**(ventilation) | 관찰, 청진, **호기말 이산화탄소**(EtCO₂). **맥박산소측정은 환기의 대용이 아니다** |
| **산소화**(oxygenation) | **맥박산소측정** — 임상적 평가보다 효과적 |
| **혈역학**(hemodynamics) | 활력징후를 정기적으로: **혈압·심박수를 5분 또는 10분 간격**(심전도·NIBP로 측정). 심장질환 환자는 **심전도** |

- **BIS**(Bispectral Index, 이분광지수): 환자의 뇌파(EEG)를 실시간으로 분석해 의식 수준과 진정·마취 깊이를 **0부터 100까지의 숫자 하나**로 나타낸 지표다.
- **EtCO₂**: 내쉬는 숨의 CO₂ 분압을 측정해 그래프로 보여 준다. CO₂를 잘 내뱉으면 환기가 잘 되는 것이고, CO₂가 점점 쌓이면 **저환기**(hypoventilation)라고 평가한다.
- **왜 맥박산소측정이 환기의 대용이 아닌가**: 산소포화도는 환기가 나빠져도 한참 뒤에야 떨어진다(특히 산소를 주고 있으면 더 늦다). 환기 자체는 관찰·청진·EtCO₂로 본다.
- 모든 감시 장치는 **적절한 알람과 경고음**이 켜져 있어야 한다.
- **깊은 진정**에서는 **심전도와 EtCO₂**를 꼭 쓴다.

## 장비(Equipment)

진정을 하는 **병원 내 모든 장소**에 다음 장비가 있어야 한다. **이게 다 주위에 갖춰져 있을 때 의식진정을 시행할 수 있다.**

- 바로 가까이에 **응급 카트**(emergency cart)
- **흡인기**(suction)
- 크기에 맞는 기도 장비, **양압 환기 수단**(means of positive-pressure ventilation), 전문 기도 장비(advanced airway equipment)
- 정맥 주사 장비
- **약물 길항제**(pharmacologic antagonist) — flumazenil, naloxone
- 기본 소생 약물
- 바로 쓸 수 있는 **제세동기**(defibrillator)

즉, 기관 삽관이 안 되면 **윤상갑상연골절개술**(cricothyrotomy), **기관절개술**(tracheostomy)까지 할 수 있는 모든 것, 심폐소생술에 대비한 **에피네프린과 제세동기**까지 준비되어 있어야 한다.

# 4. 진정 약물 고르기 — 이 수업의 메인

## 약물 선택(Choice of Agent)

의식진정에 쓰는 약은 진정제, 진통제, 그리고 둘을 섞은 조합이다.

- **진정제**(sedatives): 환자의 의식을 직접 떨어뜨린다(예: propofol). 불안을 줄이고 졸림(somnolence)을 일으킨다.
- **진통제**(analgesics): 통증을 줄인다(예: opioid).
- **조합**(combination): 중등도·깊은 진정을 얻을 수 있지만, **부작용 위험도 커진다**(increase adverse outcome).

## 약물별 작용 비교(Medications)

진정·진통 작용을 둘 다 가진 약도 있고, 하나만 가진 약도 있다. 이 표를 알고 있으면 약을 적절히 골라 쓸 수 있다.

| 약물 | 진정(Sedation) | 진통(Analgesia) | 기억상실(Amnesia) |
|---|---|---|---|
| Barbiturates | +++ | − | − |
| **Benzodiazepines** | +++ | − | **+++** |
| **Opioids** | ++ | **+++** | − |
| **Ketamine** | +++ | **+++** | + |
| **Ketorolac** | − | **+++** | − |
| **Propofol** | +++ | **−** | + |
| Chloral Hydrate | ++ | − | − |

- **Ketamine, opioid**: 진정 + 진통 둘 다.
- **Ketorolac**: 진통만(비스테로이드 소염진통제).
- **Propofol**: 진정만! 환자가 진정되어 있다고 통증을 못 느끼는 것이 아니다. 의식이 떨어져 있어도 유해 자극이 들어가면 **심박수·혈압이 올라갈 수 있다.** 그래서 진통제를 함께 쓴다.
- **Benzodiazepine**: 진정 + 강한 기억상실(진통 없음).
- **진정·진통·기억상실 셋 다 있는 약은 ketamine 하나**다.
- 같은 opioid라도 진정 정도가 다르다. 예를 들어 **같은 진통 용량이면 morphine이 fentanyl보다 더 깊이 진정**시킨다.

!!! exam "기출 포인트"
    9번(2022)은 "Sedative, analgesic, and amnestic"만 주고 약을 고르게 했다 → 이 표에서 셋 다 +인 **Ketamine**. Propofol(진통 −), Midazolam(진통 −), Morphine(기억상실 −)은 한 칸씩 빠진다.

## 상황민감성 반감기(Context Sensitive Half Time, CSHT)

**정의**: 약물을 일정 시간(infusion time, 그래프의 가로축 time of application) 동안 지속 주입한 뒤 **투여를 중단했을 때, 혈중 농도가 50%로 떨어지는 데 걸리는 시간**. 교수님은 "240분 주입 후 멈추고 반으로 떨어질 때까지 걸리는 시간"이라고 하셨는데, 이는 주입 시간이 240분일 때의 CSHT를 예로 든 것이다.

진정에 좋은 약은 **빨리 잠들고, 주입을 멈추면 빨리 깨는(혈중 농도가 빨리 떨어지는) 약**, 즉 **CSHT가 짧은 약**이다.

필기본 그래프(Egan 1993, Hughes 1992, Shafer 1981)를 주입 시간이 길어질 때 어떻게 되는지로 정리하면:

| 약물 | 그래프 모양 | 의미 |
|---|---|---|
| **Diazepam** | 거의 수직으로 치솟음(150분 이상) | 벤조디아제핀 계열, 제거가 잘 안 된다 → **진정에 적절하지 않다** |
| **Fentanyl** | 주입 시간이 길수록 급격히 증가(2시간 넘으면 100분 이상) | 제거가 너무 오래 걸린다 |
| Midazolam | 점점 올라 약 70분 | |
| Alfentanil | 약 60분에서 평평 | |
| Sufentanil | 서서히 올라 약 55분 | |
| **Propofol** | 서서히 올라 약 40분 | **비교적 CSHT가 짧은 약** |
| **Remifentanil** | **주입 시간과 관계없이 3–5분으로 일정** | 오래 주입해도 끊으면 3–5분 만에 반으로 떨어진다 → **빨리 깬다** |

Remifentanil은 혈액과 조직의 비특이적 에스테라제(esterase)로 바로 분해되기 때문에 몸에 쌓이지 않는다. 그래서 **진정·전신마취(정맥마취) 때 propofol + remifentanil 조합을 가장 많이 쓴다.**

!!! exam "기출 포인트"
    4번(2024) "진정을 위한 약물조합으로 가장 적절한 것" → **Remifentanil - propofol**. 7번(2023)은 "정맥마취제를 250분 투여하고도 중지 후 25분 만에 깨어 발관" 사례로 같은 조합을 물었다. 오답 보기의 diazepam, fentanyl, midazolam은 모두 오래 주입하면 쌓이는 약이고, chloral hydrate는 소아 경구 진정제다.
    ※ 확인 필요: 4번은 처치 진정에서 흔히 쓰는 fentanyl-midazolam(②)도 답이 될 소지가 있다는 의견이 있다. 강의 기준 정답은 ⑤.

## 용량 적정(Dose Titration)

이런 약물들은 환자의 상태, 나이, 성별, 체질량지수(BMI) 등에 따라 진정 정도가 다르다. **개인차가 심해서 항상 적정**(titration)**해서 주입해야 한다.**

- 진정 반응은 **연속선**(continuum)이므로, 개별 환자의 필요량이 **권장 범위를 넘을 수도 있다.**
- 진정약은 **환자의 반응과 계획된 시술에 맞춰** 적정한다. 의식 상태와 활력징후를 보며 조금씩 주다가, 원하는 깊이에 이르면 유지 용량으로 지속한다.
    - **단계적으로**(incrementally), 효과가 나타날 **충분한 시간을 두고** 준다.
    - **진정제와 진통제를 함께 쓰면 용량을 줄인다**(서로 효과를 키운다).
    - **정맥 외 경로**(non-IV route)는 **흡수 시간**을 고려한다.
    - **경구약 반복 투여는 권하지 않는다** — 흡수가 늦어 효과가 안 나는 것처럼 보일 때 더 주면, 나중에 한꺼번에 작용한다(chloral hydrate의 문제와 같다).
- 한 가지 약만 많이 주기보다 **여러 가지를 섞어 쓰고**, 줄 때마다 적정한다. 단일 약물의 부작용은 줄이고 효과는 키우기 위해서다.

# 5. 개별 약물

| 약물 | 계열 | 핵심 특징 | 역전제 | 주요 부작용 |
|---|---|---|---|---|
| **Midazolam** | 단시간 작용 benzodiazepine | 불안 해소·**기억상실**·진정 | **Flumazenil** | 무호흡, 저혈압, **소아의 역설적 흥분** |
| **Fentanyl** | 합성 opioid | 진통·진정 | **Naloxone** | 호흡억제, 무호흡, **흉벽 강직** |
| Morphine | 대표 opioid | 진통·진정 | Naloxone | opioid 공통 + 홍조 |
| Chloral hydrate | 수면제 | 소아 영상검사용, 경구·직장 | 없음 | 부정맥, 작용 예측 불가 |
| **Ketamine** | 해리성 마취제 | 진정·진통·기억상실, **호흡·혈압 유지** | 없음 | 분비물 증가, 고혈압, ICP·IOP 상승, 출현반응 |
| **Propofol** | 정맥 마취유도제 | 진정만, **항구토** | 없음 | **혈압 저하**(SVR↓), 호흡억제 |

## Midazolam — 벤조디아제핀

- **단시간 작용 벤조디아제핀**(short acting benzodiazepine)
- **불안 해소, 기억상실, 진정**(anxiolytic, amnestic and sedative). 특히 **선행성 기억상실**(약을 준 뒤의 일을 기억 못 함)이 있다.
- **역전제: flumazenil**
- 쓰는 시술: 중심정맥관(CVP)·말초삽입 중심정맥관(PICC) 삽입, 요추천자(lumbar puncture), 비위관(NG tube) 삽입, 봉합(sutures)

몸에 들어간 정맥 마취제는 배설되거나 스스로 분해되지 않는 한 꺼낼 수 없다. 하지만 **해독제(antidote)가 있는 정맥 진정제가 딱 두 개** 있다. 과량 투여되었을 때 역전시킬 수 있다는 것이 큰 장점이다.

!!! memo "암기"
    **Midazolam ↔ Flumazenil**, **Opioid ↔ Naloxone** — 이 두 개 외에는 없다. (교수님이 "꼭 기억!!"이라고 강조)

**용량·작용 시간** — 교수님이 "용량은 알 필요 없고, 기억하실 필요 없다"고 하셨다. **IV, IM, 비강(intranasal, 점막), 경구(oral) 다 가능하다**는 것, 즉 **경로가 다양하다**는 것만 기억하면 된다.

| 경로 | 용량 | 작용 시작 | 지속 |
|---|---|---|---|
| IV | 0.05–0.1 mg/kg | 1–5분 | 20–30분 |
| IM | 0.05–0.15 mg/kg | 5–15분 | 120분(평균) |
| 비강 | 0.2–0.3 mg/kg | 5분 | 30–60분 |
| 경구 | 0.25–0.5 mg/kg | 10–20분 | — |

**부작용**(adverse drug reactions)

- **무호흡**(apnea) — 의식진정에 쓰는 약물들의 공통 특징이다. 의식이 떨어지면 호흡과 기도에 문제가 생긴다(8단원에서 자세히).
    - 진정 약물은 **상부 호흡근의 긴장도**를 떨어뜨린다. 대표적으로 **혀의 긴장도가 떨어져 혀가 뒤로 넘어가 상부 기도를 막는다.** 평소 잘 때 기도가 막히지 않는 것은 기도 근육의 긴장이 유지되기 때문이다.
    - 이때는 환자가 숨을 쉬려는 **호흡 동력**(drive)은 있는데 **기계적으로 막힌** 것이다 → 삼중기도확보법을 쓰거나 삽관하면 된다.
    - 약을 더 많이 주면 **호흡 동력 자체가 사라진다** → 기계환기, 양압 마스크, 또는 **flumazenil로 역전**.
- **저혈압** — 고용량이거나 빨리 줄 때
- **소아의 역설적 흥분**(paradoxical excitement in children) — 재우려고 썼는데 아이가 오히려 기분이 좋아져 계속 말하고 설친다. 어른에게도 생길 수 있다. 약물 농도가 적절하지 않을 때 생기며, 이때는 다른 약을 써야 한다. 그래서 적정과 조합이 필요하다.

!!! exam "기출 포인트"
    11번(2021)은 이 슬라이드 내용(short acting BZ, 불안해소·기억상실·진정, flumazenil, 무호흡·저혈압·소아 역설적 흥분)을 그대로 주고 **Midazolam**을 고르게 했다. 필기자 말대로 역전제 짝만 알아도 풀린다.

## Opioid — Fentanyl

Midazolam 다음으로 많이 쓰는 것이 opioid 계열이다.

- **합성 opioid**. 진통·진정(analgesic/sedative).
- **역전제: naloxone**
- 쓰는 시술은 다양하다: 혈관조영술·심도자술(angiography/cardiac catheterization), 골수흡인(bone marrow aspiration), 흉관 삽입(chest tube placement), 요추천자
- 같은 합성 opioid 중 **remifentanil**은 CSHT가 짧아 가장 많이 쓴다(4단원).

**용량·작용 시간**

- IV 2–3 mcg/kg(보통 효과 용량). 0.5–1 mcg/kg씩 주며 적정, **1회 최대 100 mcg**
- **2–5분에 걸쳐 천천히 IV 주사**(slow IV push) — 빨리 주면 아래의 흉벽 강직·무호흡이 생긴다. 5분 뒤 반복 가능
- 작용 시작 **60초 이내**, 지속 30–60분

**부작용**(adverse effects) — **모든 opioid는 부작용이 비슷하고, remifentanil도 이 부작용을 다 가진다.**

- **호흡억제**(respiratory depression) — 정맥 진정제의 대표적인 부작용
- **무호흡** — 용량과 투여 속도에 관련
- **흉벽 강직**(chest wall rigidity) — **fentanyl의 특징**
    - **빠르게, 고용량**으로 주면 생긴다.
    - 호흡근이 뻣뻣해져 의식이 있어도 숨을 못 쉰다. 가슴이 늘어나야 양압 환기도 되는데, 늘어나지 않으니 **마스크 환기도 효과가 없다.**
    - 해결: 근육 긴장을 풀기 위해 **근이완제**(muscular paralysis)를 주거나, fentanyl 작용을 역전시키기 위해 **naloxone**을 준다. 둘 다 **항상 준비**되어 있어야 한다.
- **저혈압, 서맥**(bradycardia)
- **구역·구토**(nausea & vomiting)
- 그 밖에 변비, 딸꾹질, 기침, 빨리 주면 **히스타민 유리**

## Opioid — Morphine

**가장 대표적인 opioid**다. fentanyl과 마찬가지로 **진통 + 진정** 작용이 있고, **역전제는 naloxone**.

- 쓰는 시술: 도수정복(closed reduction), 부목 고정(splinting), 봉합
- 용량·작용 시간(넘어가도 된다): 영아·소아 0.05–0.1 mg/kg IV를 아주 천천히, 12세 초과 3–4 mg IV. 진통 작용 시작 20분, 지속 3–5시간 — fentanyl보다 **느리게 시작해 오래 간다.**
- 부작용: 호흡억제, 저혈압, 서맥, 구역·구토, **홍조**(flushing, 히스타민 유리). **모든 opioid 계열의 공통 부작용**이다.

## Chloral Hydrate

**소아에게 쓰는** 수면 유도제(hypnotic)로, 소아 진정에 널리 쓰여 왔다.

- **진통 작용이 없다.**
- 적절한 용량에서는 **호흡억제가 적다.**
- **오래 걸리는 영상검사**(핵의학 검사, MRI)가 필요한 소아에서 자주 선택한다.
- **3세 미만** 소아에서 가장 유용하다.
- 경로: **경구(PO)·직장(PR)**. 용량 50–75 mg/kg. 부작용: **부정맥**(arrhythmias)

**한계** — 그래서 잘 안 쓴다.

- **작용 시작이 비교적 느리고, 때로 믿을 수 없다**(unreliable). 경구로 주다 보니 환자마다 감수성이 달라 용량 예측이 안 된다. 잘 법한 용량을 줬는데 안 자서 계속 늘리면, 나중에 깨는 데 오래 걸린다.
- 일부 소아에서 **역설적 흥분**
- 일부 소아에서 **진정이 오래 가서**(prolonged sedation) 오래 관찰·감시해야 한다.
- 이런 한계 때문에 영상검사용 진정에는 **단시간 작용 barbiturate가 흔히 더 낫다**고 되어 있지만, 실제로는 **IV로 줄 수 있는 midazolam, ketamine**을 더 많이 쓴다.

정맥 주사를 하려면 정맥로를 잡아야 하는데 아이가 너무 설치면 chloral hydrate로 재워 놓고 시술하기도 한다. 그러나 예측이 안 되고 과량이면 깨우는 데 오래 걸려, **불가피한 경우가 아니면 잘 쓰지 않는다.**

## Ketamine — 기출 단골

**소아 영역에서 가장 많이 쓰인다.**

**해리성**(dissociative) **정맥 마취제** — 주고 나면 아이가 **깨어 있는 것처럼 눈을 뜨고 있지만, 의식은 진정되어 있는** 상태다.

- 일반적인 마취제는 뇌 전체의 기능을 억제해 깊이 재운다. Ketamine은 **뇌의 특정 부위 사이의 연결을 '해리(분리)'**시킨다. 대뇌피질과 변연계 사이 신호를 차단해 통증 자극이 대뇌피질로 전달되지 않으므로 **강력한 진통·진정** 효과가 있다.
- 하지만 **반사는 살아 있어 자발호흡과 기도 반사가 유지**되고, **눈을 뜨고 있거나 안구진탕**(nystagmus), 눈꺼풀 반사 등을 보일 수 있다.
- **진정·진통·기억상실 다 된다**(sedative, analgesic, and amnestic) — 특징적이다.
- **호흡근의 긴장도가 떨어지지 않는다!** 그래서 혀도 잘 넘어가지 않는다. **저산소증에 취약한 소아**에게 많이 쓰는 이유다.
- 쓰는 시술: 혈관조영술·심도자술, 골수흡인, 흉관 삽입

**금기**(contraindications) — 혈압·심박수·안압·두개내압(ICP)을 올려 부작용이 생길 수 있으므로, 다음 질환이 있으면 주의해서 쓰거나 다른 약으로 바꾼다.

- **두부 손상**(head injury) — ICP 상승
- **고혈압**
- **울혈성 심부전**(CHF) — 심장 부담 증가
- **갑상선중독증**(thyrotoxicosis) — 교감신경 항진 악화
- 경련을 일으킬 수 있어 **경련 병력이 있는 아이에게는 쓰지 않는다.**

**장점**(advantages)

- **호흡 동력 보존**(protects respiratory drive) — 상부 호흡근 긴장도가 유지되고 호흡억제를 덜 한다.
- **기관지 확장 효과**(bronchodilatory effects)
- **심박수·혈압 상승** — **노르에피네프린 분비를 자극**한다. 그래서 **쇼크 상태 환자에게 쓰기 좋다.**

**용량·작용 시간**

- IV 0.5–2 mg/kg을 2–3분에 걸쳐(0.5 mg/kg을 1분에 걸쳐 천천히, 필요하면 0.5 mg/kg 추가). IM 4–6 mg/kg
- 작용 시작: IV 1분 이내, IM 3–5분 / 지속: IV 5–10분, IM 15–30분

**부작용**(adverse drug reactions)

- **분비물 증가**(increased secretions) — 부교감신경의 무스카린 수용체를 자극해 침과 기도 점액이 늘어난다. 기도 개방성이 유지되어도 **분비물 때문에 막힐 수 있다.** → **항콜린제**(anti-cholinergics)를 함께 쓰면 분비를 줄일 수 있다.
- **고혈압**, **두개내압(ICP) 상승**, **안압(IOP) 상승**
- **출현반응**(emergence reactions) — 깰 때 **초조나 환각**(agitation or hallucinations upon awakening), 악몽. → **벤조디아제핀**을 준다.
- **구역·구토** → 벤조디아제핀

악몽을 꾸게 만들기 때문에 **항상 벤조디아제핀(midazolam)과 같이 처방**한다. 악몽을 꾸더라도 midazolam의 **선행성 기억상실** 때문에 깨고 나서는 기억하지 못한다.

!!! exam "기출 포인트"
    2번(2025)·14번(2020)은 ketamine 슬라이드의 특징·금기(head injury, HTN, CHF, thyrotoxicosis)·장점(respiratory drive 보존, 기관지 확장, HR·BP 상승)·"깰 때 초조·환각엔 benzodiazepine"을 그대로 지문으로 줬다. 6번(2023)은 사례형: 불안한 **6세 MRI 환아**에게 IV 약을 줬더니 **눈을 감지 않고 멍하니 천장을 주시**, 불러도 대답 없음, **자발호흡 유지**, 혈압 100/50 → 120/60·맥박 90 → 100으로 **상승** → Ketamine. Propofol·midazolam은 눈을 감고 혈압이 떨어지며, chloral hydrate는 경구약이다.

!!! memo "암기"
    Ketamine = **진정·진통·기억상실 + 호흡 유지 + 기관지 확장 + 혈압·맥박↑** / 금기 = **머리(ICP)·혈압·심부전·갑상선** / 부작용 대처 = **분비물엔 항콜린제, 출현반응엔 BZ**

## Propofol

- **정맥 전신마취 유도제**(intravenous general anesthetic induction agent). 대표적인 마취유도제이며 유지에도 쓴다.
- 마취과 의사가 하는 **감시하 마취관리**(monitored anesthetic care)에 자주 쓴다.
- **지속 주입** 또는 **10–20 mg 일시 주사**(bolus)
- **지질에 잘 녹는다.** 교수님은 "pofol을 지질에 녹여 놓은 게 propofol"이라고 하셨지만, 필기자가 찾아보니 반대로 **propofol을 지질에 녹여 만든 주사 제품 이름이 '포폴(Pofol)'**이다.
- 용량: IV 10–20 mg bolus, 25–100 µg/kg/min. 작용 시작 **1분**, 지속 **4–8분**(짧다)

**부작용**(adverse effects)

- **유의한 혈역학적 억제**(significant hemodynamic depression) — **전신혈관저항**(SVR)을 많이 떨어뜨려 정상인이어도 **혈압이 크게 떨어진다(40%까지).** SVR이 줄면 정맥환류(venous return)도 줄어 심박출량(CO)도 떨어질 수 있으므로, **쇼크 환자에게 주면 심정지**가 생길 수 있다. (ketamine과 정반대)
- **호흡억제** — 정맥 마취제의 특징. 기계환기·양압환기가 필요할 수 있다.
- **과량이면 무호흡**

**그 밖의 특징**

- **진통 효과가 없어서 진통제(주로 opioid)를 함께 써야 한다** → propofol + remifentanil 조합의 이유.
- **항구토 효과**(anti-emetic effect)가 있다! ketamine, opioid는 구역·구토를 일으키지만 propofol은 구토를 줄여 준다.
- 주고 나면 "좋은 꿈을 꿨다, 잘 잤다"는 사람이 많다. 그 효과 때문에 **불필요하게 내시경을 받으며 찾아다니는 사람**이 있어 문제가 된다.

# 6. 회복과 퇴실(Recovery and Discharge)

**진정 관련 합병증이 가장 많이 생기는 시기 중 하나가 회복기**다. 시술이 끝나 자극이 사라지면 남은 약 효과로 진정이 다시 깊어질 수 있기 때문이다. 그래서 **회복실에서도 생리적 감시를 계속**해야 한다.

회복실에서는 점수를 매겨 퇴실을 정한다(회복시 환자관리 수업에서 다룬 내용과 같은 흐름).

## 성인 시술 후·진정 후 회복 점수

| 항목 | 2점 | 1점 | 0점 |
|---|---|---|---|
| 활동(움직임) | 사지 4개를 움직임 | 2개 | 0개 |
| 호흡 | 깊게 숨 쉬고 기침 가능 | 호흡곤란·얕은 호흡 | 무호흡 |
| 순환(혈압) | 기준치 ±20 mmHg 이내 | ±20–50 mmHg | ±50 mmHg 이상 |
| 의식 | 완전히 깸 | 부르면 깸 | 반응 없음 |
| 산소포화도 | 실내 공기에서 SaO₂ > 92% | 산소 공급하에 > 90% | 산소 공급해도 < 90% |

- **성인은 9점 이상이면 퇴실**(또는 의사가 퇴실을 허락할 때).
- 한마디로 **본인 이름을 말할 수 있고, 고개를 들 수 있고, 산소 공급 없이 포화도가 유지되면** 보내면 된다.

## 소아 시술 후·진정 후 회복 점수

| 항목 | 점수 |
|---|---|
| 의식 | 깸(또는 기준 상태로 돌아옴) 2 / 자극에 반응 1 / 무반응 0 |
| 호흡 | 적절한 양으로 편하게 호흡 **3** / 호흡수나 양이 약간 감소 2 / 힘들거나 제한된 호흡 1 / 무호흡·부적절한 환기 0 |
| 순환 | 혈압·맥박이 기준 범위 2 / 기준 범위에 근접 1 / 비정상적으로 높거나 낮음 0 |
| 활동 | 의도적으로 팔다리를 움직임(또는 기준 상태) 2 / 비의도적 움직임 1 / 움직이지 않음 0 |

소아도 **9점이면 퇴실**(또는 의사 허락). 교수님은 "외울 필요는 없다"고 하셨다. 소아표는 호흡만 3점 만점이라 총점이 9점이므로, 퇴실하려면 사실상 모든 항목이 만점이어야 한다는 점만 눈여겨보자.

# 7. 진정 중 호흡 문제 — 왜 생기고 어떻게 알아채나

교수님이 강의 끝에 길게 말씀하신 내용이다.

- 의식진정에서 가장 큰 문제는 **과량 투여 시 숨을 안 쉰다는 것**이다. **모든 진정 약제의 공통점**이다(ketamine도 많이 주면 무호흡이 생길 수 있다).
- 완전한 무호흡이 오기 전에 먼저 **호흡근의 긴장도가 없어지며 혀가 넘어가 기도가 막히고 → 저산소증**이 온다.
- 저산소증이 오면 **심장보다 뇌가 먼저 손상**된다. **저산소성 뇌손상은 비가역적**이어서, 심장은 어느 정도 돌아와도 뇌는 돌아오지 않는다. 소아는 자라면서 일부 회복될 수 있지만 성인은 회복되지 않아 더 문제다.

**감시가 전부다**

- 심전도, 맥박산소측정 등 **모니터를 항상 잘 봐야** 한다.
- opioid 등 마취제를 줄 때는 **눈으로 보는 감시**도 해야 한다: **가슴이 움직이는지, 마스크에 김이 서리는지.**
- **가슴은 안 움직이고 배만 움직이면(복식호흡, 시소 호흡) 기도가 막힌 것**이다. 기도가 막히면 환자는 숨을 쉬려고 횡격막을 강하게 써서 배만 움직이고 가슴은 움직이지 않는다.
- 이런 징후를 잘 보고 있으면 **산소포화도가 떨어지기 전에 저산소증을 미리 예상**할 수 있다. 산소포화도 측정기를 달아 놓고 그 수치로 발견하는 것은 이미 늦은 편이다.
- 성형외과·치과 등에서 환자를 덮어 놓고 시술했는데 덮개를 벗기니 환자가 새파랗게(청색증) 되어 있었다면, 감시를 제대로 하지 않고 이런 징후에 집중하지 않은 것이다.

일단 감시를 열심히 하고, **이상 신호를 발견하면 다음 단원의 순서대로** 처치한다.

# 8. 기도 폐쇄 대처 순서

감시에서 이상 신호(산소포화도 저하)가 발견되면 **기도 폐쇄**(airway obstruction)를 뜻한다. 이때 **산소는 무조건 주고 있어야 한다**(provide supplemental O₂). 각 단계에서 해결되면(successful) 멈추고, 안 되면 다음 단계로 간다.

| 단계 | 처치 |
|---|---|
| 1 | **머리 젖히기**(head tilt) |
| 2 | **턱 들어올리기**(jaw thrust) |
| 3 | **도움 요청**(call for help) + **코인두 기도기·입인두 기도기**(NP·OP airway) 삽입 |
| 4 | **양압 환기**(PPV, positive pressure ventilation) 시도 |
| 4.5 | **대체 기도기**(alternative airway) — 후두마스크(LMA). 원래 순서도엔 없지만 교수님이 "여기 중간에 들어간다"고 하셨다 |
| 5 | 양압 환기로도 안 되면 **기관 삽관 준비**(prepare for intubation) |

!!! memo "암기"
    **Head tilt → Jaw thrust → NP·OP airway(+도움 요청) → PPV → LMA → Intubation**, 그리고 처음부터 끝까지 **산소 공급**

**후두경련**(laryngospasm)이 의심되면 위 순서와 별개로 **양압 환기, 또는 신경근차단제(근이완제) 투여 후 기관 삽관**이 필요할 수 있다. 성대가 반사적으로 닫힌 것이라 머리 자세나 기도기로는 풀리지 않기 때문이다.

## 1·2. 머리 젖히기 + 턱 들어올리기

한 손으로 이마를 눌러 **머리를 뒤로 젖히고**(head tilt backward), 다른 손으로 **턱을 앞으로 들어올리면**(chin lift forward) 혀뿌리가 인두 뒷벽에서 떨어져 **기도가 열린다.** 목을 젖혀야 하므로 2단원의 목 불안정성(다운증후군 등) 환자에서는 주의한다. 턱 들어올리기(jaw thrust)는 하악각을 앞으로 밀어 혀를 앞으로 끌어내는 방법이다.

## 3. 입인두 기도기·코인두 기도기

- **입인두 기도기**(oral airway, OP airway): 혀뒤쪽을 받쳐 혀가 넘어가지 않게 하는 휘어진 관. 넣는 방법
    - 설압자(tongue blade)로 혀를 누르고 넣거나,
    - jaw thrust를 한 상태에서 엄지로 기도기를 밀어 혀 뒤에 자리 잡게 하거나,
    - **뒤집어서(오목한 면이 입천장을 향하게) 넣은 뒤 돌려서** 제자리에 둔다.
    - 끝(bite block과 인두 곡선의 경계)이 앞니 근처에 오게 하고, 입술이 치아와 기도기 사이에 끼지 않았는지 확인한다.
- **코인두 기도기**(nasal airway, NP airway): 콧구멍으로 넣는 말랑한 관. 오목한 면이 경구개를 향하게 해서 **똑바로 뒤로** 넣는다. 관의 윗부분을 잡아야 저항이 클 때 관이 휘어지고, 콧구멍 가까이를 잡고 세게 밀면 비갑개(turbinate)가 떨어져 나갈 수 있다.

## 4. 양압 환기(PPV)

**마스크와 앰부백**(bag-valve mask)으로 바깥에서 압력을 가해 인위적으로 환기시키는 것이다. 원래 호흡은 흉강에 음압이 걸리면서 공기가 들어오는데, PPV는 밖에서 양압으로 공기를 밀어 넣는다.

- **두 손 마스크 잡기**: 엄지로 마스크 테두리를 누르고, 아래 손가락들로 **턱 들어올리기(jaw thrust)를 유지**하며 하악을 마스크 쪽으로 당긴다. 다른 사람이 백을 짠다.
- **한 손 마스크 잡기**(E-C 잡기): 엄지·검지로 마스크를, 나머지 손가락으로 하악을 당겨 올린다.

## 4.5. 후두마스크 기도기(LMA, Laryngeal Mask Airway) — 대체 기도기

- 끝에 **공기를 넣어 부풀리는 커프**(cuff)가 달린 마스크가 후두 입구를 둘러싸 막아 준다(shielding).
- 마스크 **끝(tip)이 식도 입구를 막아** 공기가 **기관으로만** 들어가게 한다.
- 제대로 넣으면 **후두덮개(epiglottis)와 성문(glottis)을 모두 피하고**, 마스크 끝이 하인두 바닥까지 들어간다.
- 넣는 법: 목은 굽히고 머리는 젖힌 상태에서, 오른손 검지로 LMA를 **혀 뒤로 밀어** 인두 안으로 넣고, 검지 끝으로 계속 밀어 제자리에 둔다. 권장량의 공기로 커프를 부풀리면(관을 잡지 않은 채) LMA가 살짝 밀려 나온다.

이렇게 순서대로 대처하면 환자를 **후유증 없이** 관리할 수 있다.

# 9. 기출 보충 — 소아마취 (필기본에 없음)

10번(2021)은 이 수업으로 분류된 소아마취 문제다. 필기본에는 없으니 보기에 나온 내용만 정리한다.

| 보기 내용 | 옳은 내용 |
|---|---|
| 상기도 감염(누런 콧물, 잦은 기침, 발열)이 있어도 정규 수술 연기 불필요 | **틀림.** 누런 콧물·발열을 동반하면 **급하지 않은 수술은 연기**한다(보통 2–4주). 기도 과민성이 높아 후두경련·기관지경련 위험이 크다 |
| 4개월 아기는 모유를 2시간 전까지 | **틀림.** 모유는 **4시간**(2단원 금식표) |
| 기관내 튜브 깊이 "12 + 연령/4" | **틀림.** 입 기준 깊이는 **12 + 나이/2** cm. 나이/4는 튜브 **내경**(4 + 나이/4 mm) 공식이다 |
| **소아 기관은 깔때기 모양으로 윤상연골 높이에서 가장 좁다** | **정답.** 성인은 성문이 가장 좁다 |
| 소아 후두는 성인보다 낮게 위치 | **틀림.** 소아 후두는 **더 높다**(C3–4, 성인은 C4–6) |

!!! exam "기출 포인트"
    소아마취 문제(10번)의 답은 "윤상연골 높이에서 가장 좁다". 오답 보기의 숫자(모유 2시간, 연령/4)와 방향(낮다)이 함정이다.
