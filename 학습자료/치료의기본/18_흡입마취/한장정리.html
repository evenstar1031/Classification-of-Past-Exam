흡입마취 한 장 정리

치료의 기본 18 · 흡입마취 (2026 박준모 교수님 / 기출 2020–2025 김현지 교수님) · 이것만 이해하고 외우면 기출이 풀린다
분압이 효과를, 분배계수가 속도를, MAC이 역가를  — 교수님 "무조건 나온다"

① 분압 = 효과 왜 '농도'가 아니라 '분압'인가

  • 가스는 분압차로 이동: 기화기 → 폐포 → 혈액 → 뇌. 효과는 뇌(CNS) 분압이 결정.
  • 평형이면 폐포 분압 ≈ 뇌 분압 → 호기말(end-tidal) 가스로 마취 심도 추정. 뇌는 못 재니까.
  • 조절도 간접적: 흡입 분압(다이얼)을 돌려 조절.
  • 배설은 대부분 폐(호기) → 끄면 5–10분이면 깸. 실시간·가역 조절 가능.
  • 전신마취는 심도 '깊다/얕다', 부위마취는 '됐다/안 됐다'.

② 혈액/가스 분배계수 = 속도

  • 정의: 평형일 때 혈액 농도 ÷ 폐포 농도. 분압은 같고 농도만 다름(halothane 2.3 = 혈액 농도가 2.3배).
  • 낮을수록(혈액에 덜 녹을수록) 유도·회복 모두 빠름.
    잘 녹는 약은 혈액이 '스펀지'처럼 빨아 가서 폐포 분압이 늦게 오름.
  • 섭취(uptake)가 많을수록 → 느림 (직관과 반대!)

④ 작용 기전 정확히는 아직 모름

  • 흥분성 억제: NMDA, 니코틴성 ACh 수용체 ↓
  • 억제성 강화: GABAA(Cl⁻ 유입↑ → 과분극), glycine(척수) → 근이완 기여
  • K⁺ 통로 열고, Ca²⁺ 유입 막음. 뇌=의식·기억, 척수=움직임, 뇌간=자율반사

⑤ 약별 특징

  • N2O: 무색·무취, 진통. MAC 105% → 단독 불가, 병용.
    · 확산성 저산소증: 끊으면 폐포로 쏟아져 O2 희석 → 100% O2 5–10분
    · 폐쇄 공간 팽창(장·중이·기흉·공기색전) → 기흉·장폐색·고막성형 금기
    · 비타민 B12 산화(비활성화), CMR↑·ICP↑, 교감 자극으로 SVR 유지
  • Sevo: 냄새·기도자극 없음 → 흡입 유도(소아). 단독 유도로 삽관 근이완 가능. HR 변화 없음. long QT 환자 제한.
  • Des: 분배계수 최저 → 가장 빨리 깸. 자극적 → 유도제로 부적절. 끓는점 23 ℃·증기압 669 → 가온·가압 기화기. 경련 X(항경련).
  • Halothane: 분배계수 최고(느림), 간독성으로 안 씀. 기화기는 한 번에 하나만 열림.

⑥ MAC = 역가(세기)

  • 정의: 피부절개에 환자 50%가 움직이지 않는 폐포 농도
  • MAC 낮을수록 강한 약(적은 양으로 됨). 속도와는 무관!
    예) Halo MAC 0.75로 강하지만 느림, Des MAC 6으로 약하지만 빠름
  • 두 약 함께 → 더한다: 0.5 MAC + 0.5 MAC = 1 MAC (평균 X)
  • MAC ↓ = 예민해짐 = 요구량 ↓  /  MAC ↑ = 요구량 ↑ (덜 주면 술중각성)

⑦ 장기 영향

  • CNS: CMR ↓(대사↓)인데, 1 MAC 이상에선 직접 혈관확장이 이겨 뇌혈류·ICP ↑ → 뇌수술은 TIVA. N2O만 CMR까지 ↑. 깊어지면 뇌파 느려짐(1.5–2 MAC 등전위), 유발전위 진폭↓·잠복기↑.
  • 심혈관: SVR↓ → 혈압↓, 압수용체 반사 둔화, QT 연장.
    Iso·Des: HR↑로 CO 유지, 급히 올리면 일시적 HR·BP↑. Sevo: HR ↔. N2O: SVR 유지.
  • 호흡: TV↓ · RR↑ = 빠르고 얕은 호흡 → 분당환기량 못 지켜 PaCO2↑. 무호흡 문턱값↑, 저산소·고탄산 반응 억제, 점액섬모↓ → 무기폐. 기관지 확장(Halo·Iso·Sevo).
  • 신경근: 골격근·자궁근 이완, 근이완제 효과 증강: Des > Sevo, Iso (N2O 아님).
기출 단골 함정 — 이렇게 나오면 틀린 보기
  • ✗ MAC 감소 = 요구량 증가 / MAC 증가 = 요구량 감소
  • ✗ 만성 알코올 → MAC 감소  (만성 = 증가, 급성 = 감소)
  • ✗ MAC 높을수록 강하다 / MAC이 낮으면 유도가 빠르다
  • ✗ 섭취량 많을수록·분배계수 클수록 유도가 빠르다
  • ✗ 회로 용적이 작으면 느려진다 / FGF가 높으면 느려진다
  • ✗ 휘발성 마취제가 CMR을 증가 / 뇌압을 낮춘다
  • ✗ 억제성 전달을 억제해 근이완 (강화)
  • ✗ SVR 증가 · QT 감소 · 압수용체 반사 강화 · 깊고 빠른 호흡
  • ✗ Des가 발작·경련 유발 / N2O가 ICP 감소 / N2O 냄새 있음
  • ✗ N2O를 기흉·장폐색·임산부에 우선 사용 / 단독으로 충분
  • ✗ 두 약 MAC은 평균 / 비만·성별·수술시간이 MAC을 바꾼다
