# 0. 이 수업을 공부하는 법

**박성식 교수님**(마취통증의학교실)의 「정맥마취제 및 전정맥마취(Intravenous Anesthetic Agents and Total Intravenous Anesthesia)」 수업이다. 2부의 기출 13문항(2020–2025, 2022년 2문항은 필기본에서 옮김)은 거의 전부 **"다음 다섯 약 중 ○○인 것은?"** 형식이고, 보기로 나오는 약도 diazepam, ketamine, midazolam, propofol, thiopental, rocuronium, succinylcholine, remifentanil, sevoflurane 정도로 매년 비슷하다.

!!! key "핵심"
    - 약 이름을 보면 **① 어느 요소(진정 / 진통 / 근이완)의 약인지 ② 그 약만의 특징 한 가지**가 바로 나와야 한다. 2단원의 분류표에서 밑줄 친 약은 "다 알고 있어야" 한다.
    - 해마다 되풀이된 주제는 네 가지다 — **마취의 3대 요소와 근이완제**(2020·2021·2023·2025), **context-sensitive half-life가 가장 짧은 약 = propofol**(2021·2025), **syringe pump로 쓸 수 없는 약 = sevoflurane**(2023·2024), **ketamine의 특이점**(2022·2024).
    - 학습목표 다섯 가지: 정맥마취제의 분류와 약제, 임상적 활용, 신경근차단제의 분류와 약제, 신경근차단제의 길항제, 마취의 주요 요소와 전정맥마취에 쓰는 약제.

# 1. 마취 방법과 마취의 3대 요소

## 마취 방법의 종류 (Anesthetic Methods)

수술받는 환자의 상태도 다양하고 수술의 종류도 다양하므로 마취 방법도 여러 가지다. 앞 시간(18강)에 배운 흡입마취는 이 가운데 전신마취의 한 갈래다.

| 방법 | 내용 |
|---|---|
| 1. **전신마취**(general anesthesia) | **흡입마취**(inhalational anesthesia): 흡입마취제 사용 / **전정맥마취**(TIVA, Total IntraVenous Anesthesia): 정맥마취제만 사용 |
| 2. **감시마취관리**(MAC, Monitored Anesthetic Care) | 내시경(수면마취)처럼 비교적 가벼운 시술에 쓴다. 환자의 **호흡은 살려 두면서** 살짝 재워 두는 정도의 마취 |
| 3. **부위마취**(regional anesthesia) | **중추신경축 차단**(central neuroaxial block): 국소마취제로 척수 수준을 차단(척수마취, 경막외마취) / **말초신경 차단**(peripheral nerve block): 궁둥신경(sciatic n.), 종아리신경(peroneal n.) 등 |
| 4. **국소마취**(local infiltration) | 봉합할 때 봉합 부위만 마취하는 경우 |

여기서 MAC은 감시마취관리의 약자다. 18강의 MAC(최소폐포농도, minimum alveolar concentration)과 글자는 같지만 전혀 다른 말이다.

## 마취의 3대 요소 (Anesthetic Components)

전신마취는 세 가지를 동시에 만족해야 한다(Pinsker, 1986). 세 요소를 각각 다른 약이 맡는다.

| 요소 | 뜻 | 맡는 약 |
|---|---|---|
| **의식 소실**(unconsciousness) | 의식이 없어야 한다 | **흡입마취제 또는 진정제**(inhalational or sedative agents) |
| **스트레스 반응 억제**(attenuation of the stress response) | 통증도 막아야 한다 | **아편유사제**(opioids) |
| **마비**(paralysis) | 환자가 **움직이지 않게** 해야 한다 | **신경근차단제**(NMBAs, NeuroMuscular Blocking Agents) |

통증을 막지 못하면 카테콜아민(catecholamine)이 분비되어 혈압이 오르고 심장에 무리가 갈 수 있다. 의식이 없어도 진통제가 따로 필요한 이유다.

!!! exam "기출 포인트"
    - 2부 12번(2020): "3대 요소 중 **수술 중 움직임을 막기 위해** 쓰는 약" → rocuronium. 함정 보기는 **sugammadex** — 근이완제가 아니라 rocuronium의 역전제다.
    - 2부 11번(2021): "신경근접합부에 작용하여 **paralysis**를 일으키는 약" → rocuronium.
    - 2부 2번(2025): 같은 내용을 "신경근접합부에 작용하여 **근육 수축을 일으키는** 약"이라고 물었고 정답은 rocuronium이었다. 필기본에도 이 표현에 물음표가 붙어 있다.

※ 확인 필요: 2부 2번(2025)의 "근육 수축을 일으키는"은 rocuronium의 작용(수축을 막아 마비시킴)과 반대되는 표현이다. 문제 문장은 그대로 두었고, 보기 중 신경근접합부에 작용하는 약이 rocuronium 하나뿐이라 정답은 달라지지 않는다.

# 2. 마취에 쓰는 약의 분류

## 약의 큰 갈래 (Drugs Used in Anesthesia)

| 갈래 | 속하는 약 | 쓰이는 마취 |
|---|---|---|
| 흡입마취제(inhalation anesthetics) | 18강 | 전신마취 |
| **정맥마취제**(intravenous anesthetics) — 이번 시간 | **진정제**(sedatives): 의식 소실 담당 / **아편유사제**(opioids): 스트레스 반응(통증) 억제 담당 / 기타(others) / **신경근차단제**(NMBAs): 마비 담당 | **전신마취, MAC** |
| 국소마취제(local anesthetics) | 척수마취, 경막외마취 등에 사용 | 부위마취, 국소마취 |

## 요소별 분류표 — 필기본에 별표

어느 요소를 막느냐에 따라 나눈 표다. **굵은 글씨**가 강의 자료에서 빨간 밑줄을 친, 임상에서 흔히 쓰는 약이다. "밑줄 친 약들은 다 알고 있어야" 한다.

| 의식 소실 — 흡입마취제 | 의식 소실 — 진정제 | 진통(스트레스 반응 억제) — 아편유사제 | 신경근차단제(움직임 억제) |
|---|---|---|---|
| Ether | **Propofol** | **Morphine** | Curare |
| Nitrous oxide | **Benzodiazepine**: valium(= diazepam), midazolam, **remimazolam** | Demerol(= meperidine) | Pancuronium |
| Chloroform | **Ketamine** | **Fentanyl** | **Vecuronium** |
| Halothane | Etomidate | Sufentanil | **Rocuronium** |
| Isoflurane | **Barbiturates** | Alfentanil | **Atracurium** |
| **Desflurane** | | **Remifentanil** | |
| **Sevoflurane** | | | |
| Xenon | | | |

- **Demerol**은 meperidine의 상품명, **valium**은 diazepam의 상품명이다. 시험에는 성분명(meperidine, diazepam)으로 나온다.
- Benzodiazepine 계열은 이름이 **-zolam, -zepam**으로 끝난다.
- sevoflurane은 흡입마취제 칸에 있다. 흡입마취제는 기화기로 주는 약이므로 **syringe pump로 줄 수 없다**(8단원).

!!! exam "기출 포인트"
    - 2부 5번(2023): "opioid에 해당하는 약" → **meperidine**. 나머지 보기(diazepam, ketamine, propofol, thiopental)는 모두 진정제 칸의 약이다.
    - 2부 3번(2024): "**진정제이지만 진통 효과가 있는** 약" → **ketamine**. 함정은 meperidine — 필기본 표현으로 "진정 효과가 있는 **진통제**"이지 진정제가 아니다. propofol과 barbiturate(thiopental)는 진정 효과만 있다.

!!! memo "암기"
    - 진정제: propofol · benzodiazepine(-zolam, -zepam) · ketamine · etomidate · barbiturate(thiopental)
    - 아편유사제: morphine · meperidine · fentanyl 계열(-fentanil)
    - 신경근차단제: -curonium, -curium + succinylcholine

# 3. 정맥마취제의 약동학

## 3구획 약동학 모형 (Three-compartment Pharmacokinetic Model)

정맥으로 들어간 약이 몸 안에서 어떻게 퍼지고 없어지는지를 세 구획으로 나누어 설명하는 모형이다.

| 구획 | 무엇인가 | 설명 |
|---|---|---|
| **V1 중심 구획**(central compartment) | **혈액** | 약(drug input)이 처음 들어오는 곳 |
| **V2 빠른 말초 구획**(fast peripheral compartment) | 혈류가 **많은** 조직: 뇌, 간 등 | V1과 빠르게 주고받는다(k12, k21) |
| **V3 느린 말초 구획**(slow peripheral compartment) | 혈류가 상대적으로 **적은** 조직: 근육, 지방 | V1과 천천히 주고받는다(k13, k31) |
| **효과처**(effect-site) | 약효가 실제로 나타나는 곳 | 약이 혈액에서 효과처로 확산되어(k1e) 약효가 나타나고 다시 빠져나온다(ke0) |

- k는 구획 사이의 이동 속도상수다. k10은 중심 구획에서 몸 밖으로 없어지는 속도로, **대사·배설**에 해당한다(clearance 1). clearance 2, 3은 각각 V2, V3로 옮겨 가는 구획 간 청소율이다.
- 약을 끊었을 때 혈중 농도가 떨어지는 속도는 대사·배설만이 아니라, 말초 구획에 쌓였던 약이 **혈액으로 되돌아오는 양**에도 좌우된다. 이것이 8단원의 context-sensitive half-life로 이어진다.

## 정맥주사한 약의 분포 (Distribution of Intravenous Agents)

한 번 주사한 약이 시간에 따라 어디에 있는지를 그린 그래프(가로축 1–300분, 세로축 투여량의 %)를 읽는 법이다.

| 곡선 | 시간에 따른 변화 | 의미 |
|---|---|---|
| **혈액**(blood) | 처음에 가장 높고 계속 감소 | 다른 조직으로 퍼지면서 줄어든다 |
| **VRG**(Vessel-Rich Group, 혈관이 풍부한 조직 = 앞의 V2) | 주사 직후 올라 1–2분에 최고, 이후 감소 | 약이 들어오면 **우선 VRG의 농도가 올라간다** → 뇌에 빨리 도달하므로 효과가 빨리 나타난다 |
| **근육**(muscle) | 10–30분쯤 최고, 이후 감소 | 지방만큼은 아니지만 약효 지속시간이 길다 |
| **지방**(fat) | 천천히 올라 100–300분에 최고 | 약이 사라지는 데 시간이 걸린다 → **숙취 효과(hangover)** 가 이어져 마취제로 쓰기에 부적절해진다 |
| **대사된 양**(amount metabolized) | 계속 증가 | 대사를 통해 몸에서 사라진다 |

따라서 **지방이나 근육에 쌓이지 않는 약일수록 onset(작용 시작)과 offset(작용 소실)이 모두 빨라** 마취제로 쓰기에 적합하다.

!!! exam "기출 포인트"
    2부 13번(2020): "정맥주사한 약제의 농도 peak가 **가장 늦게까지 유지되는** 기관" → **지방세포**. 순서는 혈액 → VRG(뇌·신장 등) → 근육 → 지방. 보기의 뇌와 신장은 VRG라서 가장 먼저 오르고 먼저 떨어진다.

# 4. 진정제 (Sedatives)

## 진정제 1 — Barbiturate: thiopental

초기에 개발된 약이지만 문제가 많아 지금은 잘 쓰지 않는다. 필기 표현으로 **"부작용이 너무 많아서 현재는 사실상 퇴출된 상태"** 다.

약동학과 용액

- 간에서 대사되어 소변으로 배설된다(liver – urine).
- 마취 유도(induction) 용량: **3–5 mg/kg**
- **지방 축적**(fat accumulation, 재분포 redistribution)이 많다 → 강의 자료 표현은 "short duration and slow recovery". 한 번 주사하면 뇌에서 다른 조직으로 재분포되어 작용 자체는 짧게 끝나지만, 지방에 쌓인 약이 천천히 빠져나와 완전히 회복되는 데는 오래 걸린다는 뜻이다.
- 용액이 **알칼리성**이다[2.5% 용액의 pH 10.6]. 그래서 생기는 문제가 세 가지다.

| 상황 | 결과 |
|---|---|
| 혈관 밖 유출(extravasation) | 정맥염(phlebitis), **조직 괴사**(necrosis), 신경 손상 |
| 동맥 내 주사(arterial injection) | **동맥 연축**(arterial spasm), 말초 괴사 |
| 침전(precipitation) | 폐색(occlusion) — 약을 녹이면 가라앉는 알갱이가 생기고, 이것이 쌓여 혈관 폐색을 일으킬 수 있다 |

※ 확인 필요: 필기에는 "short duration and slow recovery" 옆에 "늦게 흡수되고 늦게 깬다"고 적혀 있는데, 강의 자료의 short duration(작용 시간이 짧다)과 맞지 않는다. 위에는 강의 자료 문구대로 풀어 썼다.

생리적 효과(physiologic effects)

| 계통 | 효과 | 기전 |
|---|---|---|
| 호흡 | **호흡 억제**(심하면 호흡 정지) | 숨뇌(medulla)와 다리뇌(pons)의 호흡중추 억제 |
| 심혈관 | **저혈압**(혈압을 강하게 낮춤) | 혈관운동중추 억제, 말초 혈관 확장 |
| 신경 | **뇌 보호**(cerebral protection) | **뇌 대사와 산소 소비 억제**, 뇌혈류 감소 → 두개내압(intracranial pressure) 감소 |

뇌 대사를 억제하는 효과는 가장 좋은 약이다. 뇌로 가는 혈류가 과해지지 않도록 유지해 뇌 손상을 줄일 수 있으므로, 마취제보다는 **뇌 보호를 위한 진정제**로 쓴다.

## 진정제 2 — Benzodiazepine

안정제 용도로 많이 쓴다. **호흡기계·심혈관계 부작용이 적어 안정적**이라는 것이 장점이다.

- 약: **diazepam**, lorazepam, midazolam, **remimazolam**(-zolam, -zepam). remimazolam은 최근에 나온 약으로 **onset과 offset이 매우 빠르다**.
- **해독제(antidote): flumazenil** — midazolam, remimazolam 등 benzodiazepine을 과하게 주었을 때 flumazenil을 주면 진정 효과를 되돌릴(reverse) 수 있다. 강의 자료 사진의 Anexate가 flumazenil, Dormicum이 midazolam의 상품명이다.
- 약동학: 간 대사 – 소변 배설. **활성 대사물**(active metabolite)이 있다 — midazolam의 1-hydroxymethylmidazolam 등.
- 용액: 수용액(aqueous solution) → **주사 시 통증이 없다**(no pain on injection). barbiturate에 비해 통증이 적다.
- **기억상실**(amnesia): 투여 전후로 기억상실이 일어난다.

## 진정제 3 — Propofol

**전 세계적으로 가장 많이 쓰는 정맥마취제**다(강의 자료에는 ketamine이 먼저지만 교수님이 propofol부터 강의하셨다).

약동학과 용액

- 간 대사 – 소변 배설
- 마취 유도 용량: **2–2.5 mg/kg**
- 고령에서 청소율이 줄어든다(reduced clearance in elderly).
- 용액: 수성 유탁액(aqueous emulsion). 우유처럼 하얗다.
- **주사 시 통증**(pain on IV injection)이 있고 가는 정맥에서 특히 심하다 → **lidocaine을 먼저** 준 다음 propofol을 투여한다(lidocaine pretreatment).
- **Propofol infusion syndrome**: 필기에는 "propofol을 1주일 이상 장기간 지속 주입했을 때 서서히 혈압과 호흡이 떨어지는 증후군"으로 적혀 있다.
- **세균 증식**(bacterial growth): propofol 자체가 세균이 자라는 배지가 될 수 있다. 필기에는 "증식을 막으려고 실온이 아닌 냉장고에 보관한다"고 적혀 있다.

※ 확인 필요: propofol 보관을 "냉장고"라고 적은 부분. 일반적으로 propofol은 실온 보관이고 세균 오염은 무균 조작과 개봉 후 사용 시간 제한으로 막는다고 알려져 있다. 필기 내용은 그대로 두었다.

빠른 작용 시작과 회복 (rapid onset and recovery)

- 단점이 크지만 이를 상쇄할 만한 장점이다. onset과 offset이 빨라 수술과 회복이 빠르다.
- **숙취 효과가 없다**(no hangover) → **외래 마취에 적합**(proper for outpatient anesthesia)
- 참고: 수면클리닉에서도 많이 쓴다고 한다(5–10분 수면으로 3–4시간 잔 효과). 연예인을 필두로 맞는 사람이 늘고 있는데 부작용과 중독성이 문제다.

생리적 효과

| 계통 | 효과 | 세부 |
|---|---|---|
| 호흡 | **호흡 억제** | 전투약(premedication)을 하지 않은 환자에게 유도 용량을 주면 **60%에서 무호흡**. barbiturate보다 무호흡이 **더 길다** |
| 심혈관 | **저혈압** | 동맥압이 **30% 감소**. 심박수에 미치는 영향은 thiopental보다 적다. 심장 기능이 떨어진 환자에게 치명적일 수 있다 |
| 기타 | **수술 후 구역·구토 감소**(↓ postop. nausea and vomiting) | 메스꺼움을 줄여 주는 항구토 효과가 있다 |

## 진정제 4 — Ketamine

다른 진정제와 반대로 가는 점이 많아 시험에 잘 나온다. 출혈이 심한 수술 등에서 특이적으로 쓸 수 있다.

약동학과 용액

- 간 대사 – 소변 배설, **활성 대사물**이 있다.
- 수용액 → **주사 시 통증이 없다**.
- **근육주사(IM)** 로도 줄 수 있다.

해리성 마취와 강한 진통 (dissociative anesthesia with profound analgesia)

- **해리성 마취**: 통증도 없고 기억도 없는데 환자가 움직인다. 눈을 뜨고 있고(eye open), 느린 안진(slow nystagmus)과 근육 움직임(muscular activity)이 보인다. 필기에는 "의식은 남아 있다"고 적혀 있다.
- **진통 효과가 아주 좋다.** 진통 효과가 없는 다른 진정제는 opioid를 함께 주어야 하지만 ketamine은 따로 그럴 필요가 없다.
- **각성 섬망**(emergence delirium): 깨어날 때 환자가 난동을 부릴 수 있다.

※ 확인 필요: 강의 자료의 "propound analgesia"는 profound analgesia(강한 진통)의 오타로 보인다.

생리적 효과

- **호흡 억제가 적다**(less respiratory depression) — 호흡 억제 효과가 거의 없다.
- **중추신경계 자극**(CNS stimulation) → **심박수와 혈압 상승**(↑HR and BP), **두개내압 상승**(↑ICP)
- **구강 분비물 과다**(excessive oral secretion) → 분비물을 줄이려고 항콜린제인 **glycopyrrolate**를 쓴다.
- 심혈관계·호흡기계 부작용 위험이 있는 환자에게 효과적이고, 과다 출혈 환자에게도 쓰기 좋아 베트남전쟁에서도 쓰였다.

    - 2부 3번(2024): "진정제이지만 진통 효과가 있는 약" → ketamine.

# 5. 아편유사제 (Opioids)

통증(스트레스 반응)을 억제하는 약이다.

## 수용체와 작용

- **수용체**: **μ**(뮤), δ(델타), κ(카파). 이 가운데 **μ가 주 수용체**다.
- **해독제: naloxone**
- 작용(opioid actions)
    - **진통**(analgesia) — opioid를 쓰는 가장 큰 목적
    - 진정(sedation)
    - **환기 억제**(ventilatory depression)
    - **서맥**(bradycardia)
    - 내성(tolerance), 의존(dependence), 중독(addiction)
    - 기타: **가슴벽 강직**(chest wall rigidity), **히스타민 분비**(histamine release)
- **기억상실 효과는 없다.** 진정 작용이 있어도 의식 소실과 기억상실은 진정제의 몫이다.

## 마취에 쓰는 opioid 비교 (Various Opioids in Anesthesia)

| 약 | 역가(potency) | 반감기(분) |
|---|---|---|
| Morphine | 1(기준) | 120–240 |
| Demerol(meperidine) | morphine의 1/10 | 180–264 |
| **Fentanyl** | **morphine의 50–100배** | 185–219 |
| Sufentanil | fentanyl의 5–10배 | 148–164 |
| Alfentanil | fentanyl의 1/4 | 70–80 |

- **remifentanil은 반감기가 3–10분으로 유난히 짧다.** 오래 주입해도 쌓이지 않아 전정맥마취에 쓴다(8단원). 강의 자료 사진의 울티바가 remifentanil이다.
- 역가 순서: sufentanil > fentanyl ≥ remifentanil > alfentanil > morphine > meperidine

# 6. 신경근차단제 (NMBAs)

마비(paralysis)를 맡는 약이다.

## 신경근접합부 (Neuromuscular Junction, NMJ)

- 운동신경 말단(nerve terminal)이 근육 위에 놓여 있는 곳이다. 전자현미경 사진에서 신경 말단 끝에 **시냅스 소포**(synaptic vesicle)가 보이고, 맞은편 근육 막에는 소포에서 나온 물질의 **수용체**(acetylcholine receptor)가 있다.
- 전달 순서
    1. 활동전위가 신경 말단에 도착하면 소포에서 **아세틸콜린**(acetylcholine, ACh)이 분비된다(그림의 1–3).
    2. ACh가 시냅스 틈새를 건너 근육 막의 수용체에 붙으면 Na<sup>+</sup> 통로가 열려 활동전위가 생기고 **근수축**이 일어난다(4–5).

## 골격근 이완제의 분류 — 필기본에 별표

**근이완제 = NMBA가 아니다.** NMBA는 골격근 이완제(skeletal muscle relaxants)의 한 종류다.

| 큰 분류 | 작은 분류 | 약 |
|---|---|---|
| **신경근차단제**(NMBAs) — NMJ에서 근육의 수용체에 붙는다 | **비탈분극성**(non-depolarizing): ACh가 아예 붙지 못하게 해 근수축이 일어나지 않는다 | Pancuronium, **Atracurium**, Vecuronium, **Rocuronium** |
| | **탈분극성**(depolarizing): ACh처럼 탈분극(근수축)을 일으킨다 | **Succinylcholine** |
| **연축완화제**(spasmolytics) | 중추 작용(centrally acting) | Diazepam, Baclofen |
| | 직접 작용(directly acting) | Dantrolene |

- 탈분극성인 succinylcholine은 지금은 거의 쓰지 않는다고 한다(이유는 아래 부작용).
- diazepam은 진정제(benzodiazepine)이면서 중추에 작용하는 연축완화제로도 분류된다. 그러나 **신경근접합부에 작용하는 약은 아니다.**

## 작용 기전 (Action Mechanism of NMBAs)

| 상태 | 수용체 통로 | 설명 |
|---|---|---|
| 정상 — ACh 없음 | 닫힘(closed, normal) | – |
| 정상 — ACh(작용제 agonist) 결합 | 열림(open, normal) | ACh가 붙으면 통로의 뚜껑이 열려 활동전위가 발생한다 |
| **Rocuronium**(비탈분극성 차단제) | **닫힌 채 차단**(closed, blocked) | 수용체 자리를 차지해 ACh가 붙지 못한다 → **탈분극 자체를 막는다** |
| **Succinylcholine**(탈분극성 차단제) | **열린 채 차단**(open, blocked) | 처음에는 탈분극이 일어나지만, 그 뒤 새로운 활동전위가 발생하지 못하게 한다 |

**Succinylcholine의 구조**: acetylcholine **두 분자가 붙어 있는 형태**다. 그래서 ACh처럼 수용체에 붙어 탈분극을 일으킨다.

ED<sub>95</sub>의 2배 용량을 준 뒤의 임상적 지속 시간(T1이 대조값의 25%로 돌아올 때까지)으로 나눈다.

| | 장시간형(long acting, 50분 초과) | **중간형**(intermediate acting, 20–50분) | 단시간형(short acting, 10–20분) | 초단시간형(ultrashort, 10분 미만) |
|---|---|---|---|---|
| 스테로이드 화합물 | **Pancuronium**, Pipecuronium | **Vecuronium**, **Rocuronium** | Rapacuronium | |

- **현재 쓰는 것은 중간형**이고, 그중 **rocuronium을 가장 많이** 쓴다.

## 부작용

NMBA 전반(adverse effects of NMBA)

- 자율신경 효과(autonomic effects)
- 히스타민 분비(histamine release)
- 알레르기 반응(allergic reaction) → 갑자기 저혈압을 일으킬 수 있다.

Succinylcholine의 부작용 — 이 때문에 지금은 임상에서 거의 쓰지 않는다.

| 부작용 | 세부 |
|---|---|
| **부정맥**(cardiac dysrhythmias) | **동서맥**(sinus bradycardia), 접합부 리듬(junctional rhythm), 심실 부정맥 |
| **고칼륨혈증**(hyperkalemia) | 대사성 산증, 저혈량증, 대량 외상, 복부 감염이 있을 때 위험 |
| 압력 상승 | **안압**(intraocular pressure) ↑, 위내압(intragastric pressure) ↑, **두개내압** ↑ |
| 근육통(myalgia) | 탈분극으로 근육이 먼저 수축하기 때문 |
| **깨물근 연축**(masseter spasm) | 깨물근이 수축해 입을 벌리지 못하게 된다 |

# 7. 신경근차단제의 길항제 (Recovery from NMBA)

근이완은 저절로 회복되기도 하지만(spontaneous recovery) 시간이 너무 오래 걸리므로, 약으로 신경근차단제의 작용을 없앤다(reversal). 방법은 두 가지다.

1. **Anticholinesterase + anticholinergic**
2. **Sugammadex**(상품명 Bridion)

이름이 비슷해 헷갈리기 쉽다 — anti**cholinesterase**(항콜린에스터분해효소제)는 ACh를 **늘리는** 약이고, anti**cholinergic**(항콜린제)은 ACh의 작용을 **막는** 약이다.

## Anticholinesterase

- **기전**: 시냅스 틈새의 아세틸콜린에스터분해효소(acetylcholinesterase, AChE)는 ACh를 acetate와 choline으로 분해한다. anticholinesterase가 이 효소를 억제하면 **ACh가 분해되지 않고 늘어난다.** 원래는 ACh와 NMBA가 수용체를 두고 균형을 이루는데, ACh의 비중이 커지면 NMBA가 수용체에 붙는 빈도가 낮아져 NMBA의 효과가 떨어진다.
- **문제**: ACh가 너무 늘어나면 전신에 **콜린성 반응**(cholinergic reaction)이 나타난다. 그래서 **anticholinergic을 함께** 준다.

| 약 | 임상 용량(mg/kg) | 최대 효과(분) | T1/2β(분) | 대사·배설 |
|---|---|---|---|---|
| Edrophonium | 0.5–1.0 | 1–3 | 110 / 34 | 간, 콩팥 |
| Neostigmine | 0.04–0.07 | 7–10 | 77 / 47 | 콩팥(75%) |
| **Pyridostigmine** | 0.14–0.25 | 10–15 | 112 / 12 | 콩팥(70%) |

- 필기에 따르면 **pyridostigmine을 가장 많이** 쓴다.
- 작용 시작은 edrophonium이 가장 빠르고 pyridostigmine이 가장 느리다. 용량은 neostigmine이 가장 적다.

※ 확인 필요: T1/2β 칸에 숫자가 둘씩 적혀 있는데(110 / 34 등) 각각 무엇을 뜻하는지는 강의 자료와 필기에 설명이 없다.

## Anticholinergic

anticholinesterase로 늘어난 ACh의 부작용을 줄이려고 함께 준다.

| 작용 | Atropine | Scopolamine | **Glycopyrrolate** |
|---|---|---|---|
| 타액 분비 억제 | + | +++ | ++ |
| 진정, 기억상실 | + | +++ | **0** |
| 중추신경계 독성 | + | ++ | **0** |
| 위-식도 괄약근 이완 | ++ | ++ | ++ |
| 산동과 모양체근 마비 | + | ++ | **0** |
| 심박수 증가 | +++ | + | ++ |

- **glycopyrrolate를 가장 많이** 쓴다. 중추 작용(진정·기억상실, 중추신경계 독성)과 눈에 대한 작용이 **없으면서** 타액 분비 억제와 심박수 증가 효과는 충분하다.
- **scopolamine**은 타액 분비 억제와 진정·기억상실이 가장 강하고, **atropine**은 심박수 증가가 가장 강하다.
- glycopyrrolate는 ketamine의 분비물 과다를 줄이는 데도 쓴다(4단원).

!!! exam "기출 포인트"
    2부 9번(2022): "신경근차단제 역전을 위해 투여하는 약 중 **cholinergic side effect를 차단**하려고 쓰는 약" → **glycopyrrolate**(anticholinergic). 함정은 **pyridostigmine** — anticholinesterase로, 역전 자체를 맡고 부작용을 만드는 쪽이다. 원본 오답노트는 anticholinergic으로 atropine, scopolamine, glycopyrrolate를 들었고, sugammadex는 "신경근차단제 자체를 cage 안에 가두는" 새 역전제라고 설명했다.

## Sugammadex (Bridion)

- **한계를 해결한 약**: anticholinesterase는 콜린성 부작용이 생기고, anticholinergic으로 부작용은 막을 수 있어도 **NMBA의 농도 자체는 줄이지 못한다.**
- **기전**: 가운데 **구멍이 뚫린 고리 모양** 분자다. 구멍 안에 **rocuronium이 들어가 갇히면**(encapsulation complex) 신경근접합부에 작용하지 못한다. NMBA의 작용 자체를 없애는 것이다.
- 필기 표현으로 "NMBA만 억제하고 나머지 부작용은 전혀 없다." 덕분에 anticholinesterase를 거의 쓸 필요가 없게 되었다.

| | Anticholinesterase + anticholinergic | Sugammadex |
|---|---|---|
| 기전 | ACh를 늘려 NMBA와 경쟁시킨다 | rocuronium을 직접 감싸 없앤다 |
| NMBA 농도 | 줄이지 못함 | 줄임 |
| 콜린성 부작용 | 있음 → anticholinergic 필요 | 없음 |

!!! memo "암기"
    - 역전 조합: **pyridostigmine**(anticholinesterase) + **glycopyrrolate**(anticholinergic)
    - **rocuronium ↔ sugammadex**(Bridion)

# 8. 전정맥마취 (TIVA)

## 전정맥마취란

**정맥마취제만으로 마취를 유지**하는 방법이다(maintenance of anesthesia with intravenous anesthetics). 흡입마취제는 환자의 호흡을 통해 전신으로 퍼지고 어디로 퍼지느냐에 따라 염증 반응을 일으킬 수 있다는 문제가 있어, 흡입마취 없이 정맥으로만 투여하자는 데서 나왔다.

| | 내용 |
|---|---|
| **장점** | **마취의 각 요소를 따로 조절**할 수 있다(separated control of each component) — 통증 억제가 필요하면 opioid만 더 주고, 진정이 필요하면 진정제만 준다 / **환경 오염이 없다**(free from environmental contamination) — 흡입마취제처럼 수술실로 퍼지지 않는다 |
| **단점** | 마취 깊이를 볼 적절한 감시 장치가 없다(no proper monitor for anesthetic depth) / 회복 속도가 사람마다 다르다(variable recovery rate) / 약동학 정보가 충분하지 않다(not enough pharmacokinetic information) |

단점은 교수님이 "각자 읽어 보라"고 하신 부분이다. 흡입마취는 호기말 농도로 마취 깊이를 짐작할 수 있지만(18강) 정맥마취제는 그런 지표가 없다는 점과 연결해 두면 된다.

## 이상적인 정맥마취제 (Ideal Intravenous Anesthetics)

**굵은 글씨**가 강의 자료에서 빨간색으로 강조한 항목이다.

- **빠른 작용 시작**(rapid onset)
- **주사 시 통증 없음**(no pain on injection)
- 부드러운 유도(smooth induction)
- 기억상실(amnesia)
- **짧은 작용 시간**(short action duration)
- 비활성 물질로 대사(metabolize to inert substance)
- **빠른 배설과 축적 없음**(rapid secretion and no accumulation)
- 심혈관·호흡에 미치는 영향이 최소(minimal cardiovascular and respiratory effect)

몇 시간짜리 수술이면 정맥마취제를 계속 투여하게 되는데, 이때 **수술이 끝난 뒤 얼마 만에 깨느냐**가 문제가 된다.

## Context-sensitive half-life — 필기본에 별표

약을 **일정 시간 지속 주입(infusion)하다가 멈춘 뒤** 혈중 농도가 절반으로 떨어지는 데 걸리는 시간이다. 가로축은 "몇 시간 동안 주입했는가", 세로축은 "멈춘 뒤 몇 분 만에 깨는가"로 읽는다. 주입 시간(context)에 따라 값이 달라지는 것은 주입하는 동안 말초 구획(근육·지방)에 쌓인 약이 혈액으로 되돌아오기 때문이다(3단원).

정맥마취제(Miller's Anesthesia 7판 그래프)

| 약 | 그래프 모양 | 5시간 주입 후 |
|---|---|---|
| Diazepam | 처음부터 거의 수직으로 올라 그래프 밖(150분 초과) | – |
| Thiopental | 급히 오른 뒤 계속 증가 | 약 150분 |
| Midazolam | 약 20분에서 시작해 서서히 증가, 8시간에 75분쯤 | 약 70분 |
| Ketamine | 처음 1–2시간은 가장 낮고, 이후 propofol보다 조금 위 | 20–30분 |
| **Propofol** | 낮은 상태로 완만하게 증가, 8시간에도 40분쯤 | 20–30분 |

- **전정맥마취에 propofol을 쓰면 빨리 깬다.** 5시간을 주입해도 propofol과 ketamine은 20–30분이면 깬다.
- **주입 시간이 2시간쯤으로 짧으면 ketamine이 propofol보다 낮다**(필기에 "2시간 → ketamine"). 두 곡선은 2–3시간 사이에서 엇갈리고, 그 뒤로는 propofol이 가장 낮다.
- 순서(긴 주입 기준): propofol < ketamine < midazolam < thiopental < diazepam

아편유사제(Egan 등, 1993)

| 약 | 그래프 모양 |
|---|---|
| Fentanyl | 주입 시간이 길어질수록 급격히 증가(약 2시간 주입에 100분 초과) |
| Alfentanil | 올라가다가 약 60분에서 평평해짐 |
| Sufentanil | 완만하게 증가해 600분 주입에 약 60분 |
| **Remifentanil** | 주입 시간과 **관계없이 바닥**(수 분) |

- remifentanil은 아무리 오래 주입해도 **거의 5분 안에** 효과가 사라진다 → 스트레스 반응 억제용으로 전정맥마취에 쓰기 좋다.
- 근이완은 rocuronium을 쓰고 끝날 때 sugammadex로 되돌린다.

!!! exam "기출 포인트"
    - 2부 1번(2025): "**4시간** 지속 정주 시 context-sensitive half-life가 가장 짧은 약" → propofol.
    - 2부 10번(2021): "**3시간** 지속 정주 시" → propofol.
    - 두 번 모두 보기에 ketamine이 함께 나왔다. 3시간 이상이면 propofol이 답이지만, **주입 시간이 2시간 이하로 바뀌면 그래프에서는 ketamine이 더 짧다.** 문제의 시간을 반드시 확인한다.

## 약을 주는 장치

| 장치 | 주는 약 |
|---|---|
| **주사기 펌프**(syringe pump) | 정맥마취제. 강의 자료 사진에는 우유같이 하얀 **propofol**, 맑은 **remifentanil**, vecuronium이 각각 걸려 있다 |
| 흡입마취제 전달 장치(마취기·기화기) | 흡입마취제 — 앞 시간(18강) 내용 |

- 사진의 펌프에 TCI(target-controlled infusion, 목표농도조절주입)라고 표시되어 있다. **목표 농도(target concentration)** 를 정해 두면 그에 필요한 만큼의 약만 들어간다. 3단원의 약동학 모형이 이 계산의 바탕이다.
- **흡입마취제(sevoflurane 등)는 syringe pump로 줄 수 없다.** 주사하는 약이 아니라 기화기로 기체로 만들어 주는 약이기 때문이다.

!!! exam "기출 포인트"
    2부 4번(2024)·7번(2023): "syringe pump를 사용할 수 없는 약" → 두 해 모두 **sevoflurane**. 나머지 보기(diazepam, remifentanil, propofol 또는 remimazolam, rocuronium)는 진정제·아편유사제·신경근차단제로 모두 정맥으로 주는 약이다. 보기에 흡입마취제가 하나만 섞여 있다.

!!! key "핵심"
    전정맥마취의 기본 조합 = **propofol**(의식 소실) + **remifentanil**(진통) + **rocuronium**(근이완, 끝나면 **sugammadex**). 셋 다 오래 주입해도 빨리 깨거나 바로 되돌릴 수 있다는 것이 공통점이다.
